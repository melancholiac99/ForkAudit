## 第一部分：为什么需要 P2

### 1.1 M0 单独的上限

M0 是单环境、单模型、冻结策略的纯测量。按 §8，最可能的结果是 **R0（只识别状态）**，理由见 1.2；而 CWGT 已经给出了"置信度在逐步路由上是 chance level"。M0 单独成文，大概只够 TMLR 或 workshop。顶会还缺四样：统一可证伪的主张、可信的 L2 标签、跨环境与跨模型的复制、实际效用的演示。

### 1.2 合作者意见里成立的两点

1. **可恢复性。** 臂 B、臂 C 是 (prompt, θ_old) 的确定函数，事后可以精确重算（M0 本来就是这样算的）。因此它们的价值只能是"**可重算但事后估计器没用上**"，而不是"**没被记录**"。`CLAUDE.md` §1 的"决策结构被丢弃"和 §4 里"rollout 时可记录"的主张，需要改成前一种说法。M0 的测量本身不受影响。
2. **模型侧信号携带的是幅度，不是符号。** 二值回报下，|A^π(s,a_t)| ≤ 1 − π(a_t|s)。也就是说，候选分布约束的是 policy-relative 信用的**幅度上界**；要知道符号，就需要 Q(s,a′) 的信息。不假设策略对替代分支的价值是校准的，这些信息就只能来自世界。
   - 这不是定理级的反驳：M0 的 A_replay 是对 4 个采样替代取均值，不是 π 加权的 A^π；`chosen_rank`、`margin` 也能借助策略的校准性携带一部分符号信息。
   - 但它给出了一个明确的先验：**B 在 L1 上的表现会好于在 L2 上。**

### 1.3 合并的理由

合作者意见把模型侧降为对照、把 W1 作为主角。M0 则以模型侧为主角。两者共用同一份执行 replay 参考信用，所以不必二选一：可以做成一个**双重分离**的检验。

## 第二部分：主张与可证伪假设

**主张（Where vs Which）：** 在 LLM Agent 的步级信用中：
- 策略内部的决策结构（臂 B、C：可由日志与 θ_old 事后重算）告诉我们信用**集中在哪里**，即状态关键性和幅度（L1）。
- 世界对未选动作的即时回应（W1：执行一步、对 Agent 隐藏的 peek）告诉我们**哪个动作更好**，即信用的符号（L2）。
- 两者合起来，可以用很少的环境步换回 k 次 rollout 的信用（REV）。

| 编号 | 假设 | 检验 |
|---|---|---|
| H-Where | B（仅 forward）在 L1 上超过 shuffle 对照，且在 L1 上优于 W1 | M1 / L1 AUROC；B − W1 的 paired 差值 |
| H-Which | W1 在 L2 的每对符号上，相对 R3（日志 + 模型侧 + 兄弟轨迹）有条件增量 | 交叉验证 ΔR²、配对 AUROC 差值 |
| H-DD（双重分离） | (B − W1) 在 L1 上 > 0，**且** (W1 − B) 在 L2 上 > 0 | 两个 paired 差值 CI 同时不含 0 |
| H-Hole（覆盖空洞） | W1 的增量集中在兄弟轨迹覆盖不到的状态（单例）和低熵状态 | 按覆盖 × 熵三分位分层报告 |
| H-REV | 每节点 k 次 peek 的 REV ≥ 2 | REV 定义见 3.6 |

## 第三部分：ALFWorld 设计增补（M0 不动）

M0 的臂 A、B、C、H1 和 V，以及 §6 的指标与 §8 的判定，全部保留，作为阶梯的 R1、R2 级。新增内容如下。

### 3.1 信息阶梯

| 级 | 可见信息 | 访问模型 | 额外成本 |
|---|---|---|---|
| R1 | 日志：prompt、chosen、观察、已选 token 的 logprob（臂 A、H1） | 仅日志 | 0 |
| R2 = R1 + M | 臂 B、臂 C、V（用 θ_old 重算） | 日志 + 旧权重 | 前向计算 |
| R3 = R2 + G | 同任务兄弟轨迹（3.4） | GRPO 组内本来就有 | 0 |
| R4 = R3 + W1 | 未选动作的一步 peek（3.3） | 执行时访问环境 | 每节点 k 次环境步 |
| R5 = R4 + W0 | TextWorld 特权事实集（**只作诊断天花板，永不作为方法**） | 特权 | 0 |
| R6 = R3 + B_m | 预算为 m 的 replay（3.6） | 回放 | m 次续跑 |

### 3.2 L2 目标的增补：每对信用

- 每个（点 t，库 1 替代 j）：C_j(t) = mean(factual 结局) − mean(替代 j 的结局)，用库 3–6 的数据，每臂 12 次。
  - 𝓛 上约 1,478 × 4 ≈ 5,900 对，按轨迹做 cluster bootstrap。
- 因为 W1 天然是"每个替代各一份"，H-Which 主检验用每对的符号；M0 的聚合 A 照常报告。
- 信度天花板：库 3+4 vs 库 5+6，每对各自计算。

### 3.3 W1：一步 peek（已在抽取，D-029）

- 对每个点，执行 factual 和库 1 的每个替代各一步，记录观察、新的合法集和 won。另有全合法集版本（`data/peek_admissible/`），用于 k 的扫描。
- ALFWorld 是确定性环境，peek 是 (s_t, a′) 的确定函数，不含续跑噪声，所以不会把 C_ref 泄露进特征。
- **W1 特征（冻结前要定，原则：通用，不写 ALFWorld 专用模板）：**
  - W1-V：一步前瞻价值 V̂(s′(a′))。把 peek 后的状态按原模板拼成 prompt，取臂 C 位置 (i) 的隐状态，再套上 V 基线的 probe（按轨迹 out-of-fold）。每对的分数取 V̂(s′(a_t)) − V̂(s′(a′))。
  - W1-T：peek 观察与任务描述的语义相似度（冻结的 `bge-small`）。
  - W1-N：通用文本统计：`Nothing happens`、观察长度、合法集大小的变化、轨迹中首次出现的实体数（信息揭示的代理）。
  - W1-P：策略对 peek 后状态的 `chosen_prob` / `entropy_q`（模型侧特征套用到世界侧状态上）。
- **对照：** 任务内 peek 错配（把 W1 换成同任务其他点的 peek）；边际保持的 shuffle（M3）。

### 3.4 G：兄弟轨迹

- 每个任务再补 7 条 rollout（seeds 另起，按 D-024 的格式），与原轨迹组成 8 条一组：700 条，约 2.8 万个生成步，单卡约 20 分钟。
- 状态匹配用 GiGPO 的 anchor 规则：当前观察文本完全相同。不使用特权事实。
- 特征：匹配状态上兄弟轨迹的成功率；在该状态执行过 a′ 的兄弟轨迹的成功率（GiGPO 步级 advantage）；覆盖数（单例 / 多次访问）。
- 原轨迹的点本身不用来定义 G（按轨迹留出）。

### 3.5 Gold 集（加深标签）

- 从 𝓛 中只按 forward 量（`entropy_q` 三分位 × 轨迹进度三分位 × 任务类型）分层抽 300 点。每臂在库 3–6 的基础上再加 20 次，到 32 次（库 7–13 的种子格式，D-024）。
- 成本约 3 万次续跑 × 0.75 s ≈ 6 h。
- 这会部分撤回 D-027：D-027 取消的是全 𝓛 的库 7–10，约 22 h，这里只加深一个子集。
- 用途：gold 集上的结果作为 L2 的高信度版本，并报告 Spearman–Brown 校正后的信度天花板。若 gold 集上 32 次/臂的半分信度仍 < 0.4，按合作者意见的 MEASUREMENT-FAIL 处理：L2 改为子目标级。

### 3.6 REV（rollout 等价价值）

- 预算 replay 估计器 B_m：每臂 m 次续跑的对比，m ∈ {1, 2, 3, 6}。
- **选择偏差：** 𝓛 是按库 1+2 选出来的，所以 B_m 不能取自库 1+2。REV 在库 3–6 内部切分：B_m 取自库 3–4，标签取自库 5–6（每臂 6 次）。gold 集上可以用库 7–13 作标签。
- REV(X) = 使 X 的误差不再优于 B_m 的最小 m（按 L2 符号 AUROC 与每对 Spearman 各算一次）。

### 3.7 事后估计器能否用上新信息（消费者检验）

把 peek 文本追加进 H1 的 hindsight pass（ρ_t + peek），看 ρ_t 能不能用上 W1。LLM judge（H2）按 §4 仍不在本阶段；若裁决允许，作为可选行。

## 第四部分：增补判定行（与 §8 R0–R5 并列，不替代）

| 读法 | 条件 | 判定 |
|---|---|---|
| WW-PASS | H-DD 成立，且 H-Which 校正后 ΔR²(W1 \| R3) ≥ 0.05、CI 下界 > 0 | Where/Which 完整成立，进入第二、三环境 |
| W-PASS | H-Which 成立，H-Where 不成立 | 世界侧是主角，M0 作为对照阶梯 |
| W-HOLE | 总体 ΔR² < 0.05，但单例或低熵分层中 ≥ 0.10、CI 下界 > 0 | 覆盖空洞论文 |

| MEAS-FAIL | gold 集半分信度 < 0.4 | 步级对比不可测，改用子目标级 |
