# E4b：回放零信用状态的训练价值（待审实验方案）

日期：2026-11-02。状态：**PROPOSED / NOT FROZEN / 未执行**。本方案只放入统一待审分支 review/pending-20261102；不更改 E4 已注册的 R-L-HEURISTIC 读法、既有结果或原始标签。方案由 E4 已观察结果驱动，因此不伪称独立提出；但 E4b 的新训练试验应在开始前冻结设计。

## 1. 研究问题

**当前策略的有限反事实续跑没有检测到动作信用差异，是否意味着这个状态没有改善未来策略的训练价值？**

当前策略 π₀ 下各动作的续跑价值 Q^π₀(s,a)，与通过偏好训练后新策略 πθ 的收益并非同一个对象。五个候选动作各续跑三次全部失败，只说明在这 15 次有限样本中观察到全零，不证明真实价值严格相等为零，更不能证明对未来策略没有训练价值。

E4b 的可证伪假说：**即使动作差异在当前策略回放中不可分辨，一步反馈形成的偏好监督仍可能产生可观的独立任务训练收益。**

## 2. E4 证据起点（事后发现，需对照源文件复核）

用户提供的 E4 后验标签分析覆盖 6,016 个训练决策点；现有读法 R-L-HEURISTIC 不变。

| 原训练组 | rejected 为事实动作 | preferred 为新探索 | 与3次回放一致/持平/相反 | 全臂回放全零点的标签占比 |
|---|---:|---:|---:|---:|
| A（32B + 一步反馈） | 100% | 40% | 10%/83%/7% | 73% |
| A′（揭示规则） | 100% | 84% | 34%/61%/5% | 47% |
| D（探索启发式） | 100% | 100% | 14%/81%/6% | 69% |
| Rnd | 100% | 28% | 7%/86%/7% | 73% |
| Bfull（回放信用） | 57% | 46% | 100%（构造导致） | 0% |

初步事实：约 73% 的训练决策点上五个候选各三次回放均失败；Bfull 只使用检测到差异的点，且 43% 的偏好对不涉及事实动作；A 与 D 约七成标签位于全零点却在 E4 有训练收益。用户提供的 Rnd 约 +4、D 约 +8.5、A/A′ 约 +11 pp 不能被直接解释为独立、可加的因果贡献。A 训练后 I 层 Fork 的 G_u 仍约 −4.17 pp（基座 −7.46 pp），不能由此推断成功率增益主要发生在 Fork 上。复核前这些统计均标为“用户提供的事后分析”。

## 3. 预先定义训练人群

冻结原 E4 训练任务和策略 π₀、原始候选五臂、事实动作、偏好源与回放原始奖励。按原五臂每臂三次续跑分类：
- Z3（观测全零）：15 个最终奖励全部为 0。
- V3（观测有差距）：至少两个候选臂的三次平均奖励不相等。
- V3-fac（事实锚定的可用回放对）：V3 中存在严格高于事实动作三次回放均值的非事实替代动作。

全成功或各臂均值相等但非全零者单列数量，不混入 Z3。三次回放分类含统计噪声，绝不可称 Z3 为“真实 Q=0”。V3-fac 是 Bfac 的结构性支持集，若不能形成事实锚定对，必须报告缺失，不能换一个不包含事实动作的 rejected 来凑数。

## 4. 主实验：四个训练臂 + 无训练基线

| 组 | 选点 | preferred / rejected | 目的 |
|---|---|---|---|
| A-zero | Z3 | 原 A 的 32B + 一步反馈 preferred，且必须为非事实动作；rejected 为事实动作 | 估计观测零信用点的训练价值 |
| A-gap | V3 | 同一 A 标注机制，非事实 preferred / 事实 rejected | 同标注法下的回放差异组 |
| Bfac-gap | V3-fac | 严格高于事实动作的最优回放替代 / 事实动作 | 修复 Bfull 与其他组的偏好对结构差异 |
| D-zero | Z3 | 原 D 探索规则选出的非事实动作 / 事实动作 | 检验 A-zero 是否超出简单探索规则 |
| Base | 无训练 | 无 | 成功率共同参照 |

**公平性硬条件**：所有训练组的偏好结构统一为非事实 preferred 对事实 rejected，唯一偏好对数量 N 相同；相同基座、tokenizer、LoRA-DPO、β、学习率、epochs、batch、优化器更新步数、上下文模板、训练 seed、评估任务与随机种子。优先沿用 E4 冻结设置（如 5e−6 学习率）；不得为 E4b 各臂根据结果重新调参。原 A 若 preferred 就是事实动作则删除该点并统计剔除率。Bfac 同分动作按冻结的确定性规则择一。点数不足时不得重复样本或变更偏好结构凑 N。

**重要限制**：A-zero 对 A-gap 必然跨 Z3/V3 的不同点，无法做到同状态匹配，因此即使数量与偏好对结构一致，也不代表已排除任务难度、轨迹位置和状态分布混淆。预注册需要预设任务类型、轨迹进度、事实动作类型、新探索候选数量、原策略成功率等协变量的分层/匹配/加权敏感性。A-zero 与 D-zero 尽可能在共同 Z3 状态 ID 上构造，同点比较标签类型；Bfac-gap 与 A-gap 还应在共同 V3-fac 支持集上比较。

是否额外添加 D-gap、Rnd-zero，由合作者在冻结前决定，禁止在看到新结果后补臂。

## 5. 实验终点和读法

**主终点**：沿用 E4 的 valid_unseen 独立任务成功率，在同一评估任务、同样 rollout 次数和评估种子上比较；任务级配对统计与聚类 bootstrap 95% CI。主要效应为 A-zero 减 A-gap 的百分点差，另报告 A-zero 和 A-gap 各自减 Base 的改进。

**主张分两档**：
1. “观测零信用点有训练价值”：A-zero 在预定独立任务和统计规则下优于 Base。
2. “观测零信用点不比有差距点差”：需预先冻结非劣界 δ、预期任务数/功效，并要求 A-zero − A-gap 的区间下界超过 −δ；仅 P 值不显著或 CI 跨零不构成非劣。

次终点：A-zero − D-zero（探索规则外的额外作用）、A-zero − Bfac-gap、共同 V3-fac 支持集上 A-gap − Bfac-gap；valid_seen、训练 seed 稳健性、训练效率、偏好分布、新探索倾向、I 层 Fork G_u 变化。Fork 回放价值仅作为机制指标，不可替代独立任务成功率。多重比较如何控制、cluster 层级、δ 和功效均须在训练前冻结。

预定结果读法：
- **E4b-SUPPORT**：A-zero 相对 Base 有收益，且达到预先冻结的 A-gap 非劣标准（或明确优于 A-gap）。支持“观测零信用不是排除训练样本的充分条件”。
- **E4b-PARTIAL**：A-zero 有收益，但对 A-gap 非劣未得到支持；只能称这些观测全零点可以训练有效。
- **E4b-COUNTER**：A-gap 明显好于 A-zero，或者 A-zero 无法证明优于 Base；强主张不成立。
- **E4b-INCONCLUSIVE**：因样本、功效、训练失败或区间不足无法判定；不得强行解释。

## 6. 三次回放噪声与复核

建议对 Z3 和 V3 做**按任务/轨迹盲抽**的独立更深回放子样本（提议每臂追加至多 20 次，冻结后视预算执行），报告全零重新分类率、各臂真实优势区间和选择标签对更深回放的符合程度。独立复核不得回流变更主分组或训练偏好。Bfull 的“100% 回放一致”是构造性关系，不能当成独立可靠性证据。

## 8. 与论文主线的关系

潜在核心标题：**Measured Zero Credit Does Not Imply Zero Learning Value**。

合适的主张是：**固定当前策略下有限反事实回放未测出动作收益差，不应被当作训练状态毫无价值的充分证据。** 即使 E4b 支持这一点，也不能声称“真实 Q 恰为零的状态总有学习价值”“回放信用整体无效”或“所有训练收益都来自探索”。
