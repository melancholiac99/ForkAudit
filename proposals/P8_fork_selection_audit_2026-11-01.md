## 0. 为什么要审计：一个可能推翻当前解释的替代机制

当前结果：在 **I ∩ Fork（184 点）** 上，P4-X 真正的首批草稿采样边际相对五臂均匀的长期收益为 **−6.82 pp**（不是早期 logp_sum 口径的 −11.1 pp）；32B + 完整决策前历史 M 为 **−6.35 pp**；32B + 带动作对应的一步反馈 F 为 **+42.70 pp**。这些都是在固定候选集与固定续跑策略下，以「具体真实世界」的反事实成功率评估的结果，而不是部署时的真实成功率提升。

存在两种不同的解释：

- **信息缺口：** 历史不足以知道哪一个尚未观察的位置有目标。F 得到真实世界的新证据，自然能更好地选中此局高价值动作。
- **条件选样：** Fork 的判定取决于实际隐藏世界与固定后续策略能否补救早期动作。假如后续策略通常能在符合自身先验的世界里纠错、却难以在意外世界里纠错，则「被检测为 Fork」可能富集于原策略对当前真实世界的低概率偏好场景。只在此子集对照「真实世界最优动作」会让合理的历史条件选择者也显得很差。

**第二条并非 Fork 定义的逻辑必然结论。** 是否发生、幅度多大、是否能解释原负收益，都必须量化。I 层还要求「某臂的一步观察揭示此前历史中没有的目标实例」，是额外的结果条件；因此新分析的主人群不能继续以 I 层定义。

一个说明可能性的例子（非数据、非定理）：历史下世界 A 概率 95%，世界 B 概率 5%；两个动作 a、b 的真实价值分别为 A 世界 (1,0.9)、B 世界 (0,1)。历史期望 Q(a)=0.95、Q(b)=0.905，选 a 合理；但如果小差距的 A 世界在有限回放下常未检出 Fork，而 B 世界的大差距常检出，那么 Fork 子集就可能使选 a 的策略相对均匀选择呈负收益。机制关键是**世界分布 × 后续补救 × 有限功效的 Fork 检测**，不是「模型选错」与「Fork」在定义上等价。

## 1. 测量对象与不能偷换的结论

固定原策略 π、原任务、同一真实隐藏状态 s、决策前观测历史 h 及候选动作集合 A_i，令：

- **状态条件续跑价值：** q_i(a) = E[R | s_i, h_i, 先执行 a、随后继续 π]。M0 的回放在估计它。
- **历史条件价值：** Q^π(h,a) = E[q(s,h,a) | h]。如果同一 h 对应多个可能世界，必须对它们的条件分布取期望。**单个历史在单个真实世界里的回放无法直接识别逐历史的 Q^π(h,a)；但在只由决策前可观测信息定义的群体上，平均状态条件 q 的无偏回放估计，可以估计历史条件下的群体平均选择收益。**
- **Fork 标签：** 在同一实际世界中，基于独立续跑库对各臂终局结果差异进行检验得到的标签；是对特定续跑策略、候选集、统计功效和具体世界的条件判定。
- **选择收益：** G_u(p,q) = Σ_a p(a)q(a) − (1/K)Σ_a q(a)。它的零点是**这 K 个候选动作的均匀分布**，不是环境中所有合法动作的先验，也不是历史条件最优策略。P4-X 已指出候选集由策略采样的前四个不同合法替代构成，会放大某些低概率动作的代表性。

令 z=(可观测历史 h、候选动作集合 A)，而 p(a|z) 仅由 z 决定。历史定义人群 H_prompt 下的选择收益为：

\[
g(s,z)=\sum_{a\in A}p(a\mid z)q^\pi(s,z,a)-\frac{1}{|A|}\sum_{a\in A}q^\pi(s,z,a),
\quad \mu_H=\mathbb{E}[g(s,z)\mid H_{\rm prompt}].
\]

当状态及历史来自原数据分布、候选生成遵循既定策略、H_prompt 不按未来结果筛选、续跑 q 为状态条件价值的无偏估计时，对 H_prompt 所有点平均 g 是群体历史条件期望收益的估计。**不需要构造孪生世界，就能检验总体均值的符号**；孪生世界只在要对某一固定历史逐点分解 Q 和隐藏状态残差时需要。均匀基线始终只是「该策略生成的 K 个候选动作均匀选」，不是全动作空间最优基线。

**主问题是 \(\mu_H\) 的符号，不是全人群与 Fork 子集 G_u 的差值。** Dead 的库 1+2 各臂 q 相同时 G_u 恰好为零；Fork 标签反而偏向检出大跨臂差异。因此 Fork 子集的负收益更强本身区分不了「策略真正有历史条件偏差」与「条件选样」。

三项不同问题必须分开报告：

1. **历史定义人群上的收益是否仍为负？** 主要报告 H_prompt 的 μ_H 符号与 95% CI，并使用 Live 内的分解解释 Fork 负收益是否被非 Fork 补偿。
2. **Fork 是否富集于当前策略低概率的「事后高价值臂」？** 注意这只是实际最优动作的**策略偏好失配代理**，不等于已测得隐藏世界的先验概率。
3. **历史已可用的信息有没有被利用？** 不观察任何新环境事实的简单历史规则，与原策略及评判者相比表现如何？

本实验可以估计**历史定义的人群平均收益**，但不能识别逐历史的隐藏状态残差；不能仅凭 Fork 条件性关联证明世界出乎策略预期，也不能把历史规则称为历史可识别信用的理论上限。逐历史分解仍需孪生世界。

### 2.2 预先确定的人群

- **H_prompt（主分析）：** 所有反事实可定义、五臂 q_12 完整，且在 t 时刻**原始 prompt 尚未出现目标实例**的决策点。**不按 Fork / Live、不按一步反馈是否出现目标、不按未来是否揭示目标筛选。** 是否处于 H_prompt 仅使用 t 之前已确定的文本与固定候选集的有效性。

## 3. 阶段 A：纯 CPU 选样审计（优先完成）

### A1. 历史定义人群上的平均选择收益（主检验 P1）

策略边际主口径：P4-X X2 的首批 32 份合法草稿中，对五个候选臂的计数各加 0.5 并归一化；敏感性包括全部草稿、chosen one-hot、logp_mean。策略只能使用原始决策上下文和候选集，不读取真目标位置、未来、一步反馈或回放价值。

**主量 P1：** 对 H_prompt 全部点的 G_u(p,q_12) 求点均值、轨迹 cluster 95% CI。并列输出 H_full、H_prompt∩Live、H_prompt∩Fork、H_prompt∩Live∩¬Fork、H_prompt∩Dead。主检验并不提前筛选 Fork 或 Live。

**Live 内精确分解：**

\[
G_u(H\cap Live)=w_F G_u(H\cap Fork)+(1-w_F)G_u(H\cap Live\cap\neg Fork),\quad
w_F=\Pr(Fork\mid H\cap Live).
\]

- 每个 bootstrap 重抽样内重新计算 w_F、两个子组均值及加权和；恒等式误差应小于 1e-12。
- 报告「非 Fork 没有正补偿」参照 w_F G_u(H∩Fork) 以及正补偿量 (1−w_F)G_u(H∩Live∩¬Fork)。是否补偿足以让总体不为负，要与 P1 联合判断。
- H_prompt 总体和 Live 归一化的均值、CI、Live 占比、两项加权贡献全部报告。**不设置 −2 pp 绝对容忍阈值**：Dead 大量零收益会稀释整体幅度，但不会使期望的符号发生系统变化。
- 补充 q 的跨臂范围分箱（0、(0,1/3]、(1/3,2/3]、(2/3,1]）、G_c、chosen 相对均匀、任务类型、turn 四分位、首个 H_prompt 点与每轨迹等权结果。全部子组报告点数、轨迹数、缺失率。
- H_prompt 与 Fork 子集的 G_u 差仍可展示，但**只能描述条件人群不同，不得用其显著性构成选样效应主判据**。

若 P1 的 CI 上界 < 0，说明在此历史定义群体、**策略自身产生的五臂候选集**中，均匀分散概率比策略原偏好有更高期望收益；不能据此证明策略对所有合法动作不理性，也不能不经过众数/类别分解就断言具体机制是「众数过度集中」。


### A2. Fork 与事后高价值臂的策略偏好（只描述，不进入联合读法）

人群为 H_prompt∩Live。用库 1+2 的 q 找实际世界估计最佳臂，用库 3–6 的原标签判断 Fork，保持两组回放噪声尽量独立。并列最佳臂时使用整个最佳集合的策略概率质量减去它的均匀概率质量；库 1+2 各臂相同时代理为 0。

报告唯一最佳臂的 p_best 分箱（0–0.2、0.2–0.4、0.4–0.6、0.6–0.8、0.8–1）与 Fork 率、点数、轨迹数，以及并列比例。可描述性展示对 q_12 跨臂范围、E_new 臂数量、任务类别、进度的调整模型与 bootstrap CI，但**不要求调整后关联显著，也不设置 S3 检验或加入联合读法**。

原因：Fork 的检测功效与真实跨臂差相关；用于控制的 q_12 range 自身有有限回放噪声，也与最佳臂代理来源相同。调整分析并不足以识别隐藏世界的 surprise。所有结果只允许表述为「Fork 与策略对事后高价值候选的偏好存在/不存在描述性关联」，不能写 Fork 定义必然筛出违背策略信念的世界。


### A3. 统计协议

- 一律使用既有 q_12 与旧标签，不重新采样、重新定 Fork 或根据结果更换候选集；
- 统计单位为决策点，区间按 **轨迹 cluster bootstrap 10,000 次，预置 seed=20261101**；两人群嵌套时同一 bootstrap 权重、配对求差。另报每轨迹等权敏感性，避免长失败轨迹过度代表；
- 百分点结果保留两位、95% 百分位区间；所有预先列出的子群包括样本量和缺失率；Gold 仅作为既有独立子样本的敏感性，不把其 300 点当作总体随机验证集；
- 合成自测至少包含：历史理性策略在 Fork 子集负收益但总体正收益（常见世界必须有小幅真实优势）、历史层面真正负收益、Live/Fork 分解恒等式、Dead 价值完全相等则 G_u=0，以及无富集反例。合成测试不读任何项目科学数据；新收益分析前再进行旧 I∩Fork 的 184 点与 −6.82 pp 重算门。

## 4. 阶段 B：历史可用信息规则（CPU）

所有规则选择动作时只能读取**自身标定的信息预算**里的 t 前观察和固定候选集；回放 q_12 只在选完后评估。不得利用真目标位置、一步反馈、后续事实或 Fork 标签来选动作。每条规则与其对应模型的**信息条件必须对齐**。

- **R0：** 五臂均匀，G_u=0。
- **R1-window（主要同信息基线）：** 只根据**当时原 prompt 内的两步历史窗口**定义 E_new：尚未 go to 的地点、尚未 open 的容器。存在 E_new 时在其臂内均匀，否则退回 R0；与原策略、7B/S、32B/S 同信息预算比较。
- **R1-full（额外历史基线）：** 采用完全相同的 E_new 规则和退回逻辑，但使用**所有 t 前事实历史**。主对照是 7B/M、32B/M。相对原策略的结果可并列给出，但要明确同时改变了历史信息量与选择规则。
- **R2（严格负证据）：** 仅当可见历史明确显示「相应位置已经检查且无目标」，并能与候选动作对应时排除。返回某个此前去过的位置仍可能是必要路径动作，不能自动一律排除。主版 R2-full 与 M 比较；可实现时补 R2-window 与 S 比较。文本不可可靠核验时报告 UNAVAILABLE。
- **R3（训练先验，条件扩展）：** 若独立 ALFWorld 训练元数据存在可靠的目标物体类别 × 容器类别频率，则 Dirichlet(+1) 平滑，只使用类别级先验分布，不调用测试场景的真实目标位置。在看任何 R3 收益之前固定训练样本排除、映射规则、平滑、回退与 SHA256；不可行则 UNAVAILABLE。

对 H_prompt 总体、H_prompt∩Live、H_prompt∩Live∩¬Fork、H_prompt∩Fork 及 H_full 逐项报告每条规则的 G_u、相对 R0 的收益、**同信息对照的配对差**与 CI，以及每条规则的有效覆盖率和 R0 回退比例。Fork 子集上的规则优劣不能单独证明模型有历史利用缺陷。


## 5. 阶段 C：评判者补打分（GPU，A/B 通过完整性门后执行）

先冻结基于历史的抽样名单，**不允许根据 Fork / Live / q / 既有评判收益抽点**。建议每条含 H_prompt 的 factual 轨迹最多取 8 点，按 SHA256("P8-v1|traj_id|turn") 升序抽取；全取不足 8 点的轨迹。存抽样名单、每轨迹纳入概率与 SHA256，记录总体/样本的人群构成；估计总体点均值使用 inverse-inclusion weights，按轨迹 bootstrap。

在该名单上，按已冻结的 P4 E2 / E2-M 模板与同 checkpoint / revision 计算 7B、32B 的 S（决策上下文）、M（补完整决策前历史）、L（完整 factual 未来）、F（五臂对应的一步反馈）。已有相同条件完全一致的打分可复用；F 缺 peek 的点先单列覆盖情况，不能因其 Fork 标签而补取样。**S/M 是历史可用信息的公平对照；L/F 是带额外信息的诊断条件，不是同等信息预算的部署算法。**

如果阶段 C 需要新的候选一步执行，只能按原环境一致性门逐步验证，不能使用任何续跑终局标签指导执行。记录总 contexts / candidate sequences、GPU 秒数、token 数、模型版本与数值 TV；先用既有 E2 点做重现门（各条件收益差 <1e−9 或按已记录的数值容差核验）再大规模打分。

主要比较：在**同一抽样人群**上，R1-window 与原策略及 7B/S、32B/S 对照；R1-full、R2-full 与 7B/M、32B/M 对照；再报告 32B/F 对 32B/M 和 R1-full 的额外收益。S/M 属于历史可用信息对照，L/F 属于额外/特权信息诊断。Fork 子集比较仅为条件性补充。若抽样不覆盖足够的 Live 或 Fork，照报 UNDERPOWERED，不可转而按结局补抽。预计几 GPU 小时，具体依服务器实测再登记，不将估算视为上限。

## 6. 待审核冻结的新判定：P1 为主、P2 为机制

**旧 S1、S2、S3 不再作为判定门。** 旧 S1 的 Fork-vs-all 差值会由真实动作差异的检测条件放大；旧 S2 的 −2 pp 固定阈值受到 Dead 零值稀释；A2 的 p_best 分析只作描述。不得因为 A2 的趋势显著就把它恢复为证明世界 surprise 的标准。

| 检验 | 操作性定义 | 可解释范围 |
|---|---|---|
| **P1（主检验）** | 原策略 X2 在 H_prompt 所有点上的 G_u：95% CI **上界 < 0** 为 NEG；**下界 ≥ 0** 为 NONNEG；否则为 INCONCLUSIVE | NEG：在固定五臂候选中历史群体平均收益低于均匀；NONNEG：该人群平均收益有非负方向的统计支持；跨 0 不能说「不存在负收益」 |
| **P2（非 Fork Live 正补偿）** | H_prompt∩Live∩¬Fork 上 G_u 的 CI **下界 > 0** | 说明 Fork 外有小幅正收益贡献；是否足以抵消 Fork 负值，必须结合 w_F 加权分解和 P1 |
| **S4（历史规则机会）** | R1-window − 原策略，在 H_prompt 同点配对收益的 95% CI 下界 > 0 | 在同等 prompt 信息条件下存在可操作的历史规则改善空间；R1-full 与 M 单列，不与原策略混为同信息比较 |
| **S5（一步反馈的额外收益）** | 同一盲抽打分样本上 32B/F − R1-full 和 32B/F − 32B/M 的配对 CI 下界均 > 0 | 带额外观察的本世界选臂收益更高；不能自动认作「纯隐藏状态残差」 |

**主联合读法（按序）：**

1. **R-P8-MISDIRECT-HISTORY**：P1=NEG。负收益不再只是 Fork 条件现象；但它只相对于本候选集均匀分布成立，不能推论策略全局不理性或直接断言某个众数动作导致问题。
2. **R-P8-SELECTION**：P1=NONNEG 且 P2 成立；仅当 H_prompt∩Fork 的 G_u 点估计仍为负时，才解释为「Fork 上的负值被非 Fork Live 的正贡献抵消」。若 Fork 不为负，则报告总体非负和非 Fork 正效应，不称选择偏差。
3. **R-P8-INCONCLUSIVE**：P1 的 95% CI 跨 0。P2 为正也不能自动改判为 SELECTION。
4. **R-P8-PARTIAL**：其余组合分别解释，不硬造主线。
5. **R-P8-UNDERPOWERED/UNAVAILABLE**：关键输入缺失、轨迹太少、数值核对失败时对应项目只报告不足，不更换子集或指标。

S4、S5 作为**独立的正交结果**在任何主联合读法下均报告；A2 完全不参与联合判定。必须同时列出 H_prompt、H_prompt∩Live、w_F × G_F、(1−w_F) × G_nonFork、无补偿参照及完整加权和；Dead 的零收益稀释不能拿来预先设置任意容忍区间。

所有结果都是已见 ALFWorld 数据后的追加审计；即使先固定新方案，也不构成外部独立复现。P1=NONNEG 不代表历史条件最优，更不等于证明策略从未在特定世界选错。

## 9. 最终对 V3 的决策问题
