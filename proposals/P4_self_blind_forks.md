## 第一部分：为什么需要 P4

### 1.1 M0 的结论与它的天花板

M0 的描述性结果（REVIEW §1）是一个干净的双重分离：兄弟轨迹定位 Dead（B1 0.84），一步 peek 定位 Fork（B2 0.67），符号要回放。研究者原始假设（决策结构携带信用信息）只部分成立：B_multi 优于标量置信度，但不超过隐状态探针，五个家族无一被指认。

按目前写法，这些结论容易被读成常识：

- "信用藏在未执行的动作里"：反事实不可观察，是定义。
- "执行候选一步能获得信息"：TreeHCA、Critical-State RL 已执行候选。
- "动作可控的方差很小"：CARL 已报告过半数状态重采样后对结果几乎无影响。
- "标量优势遗漏替代偏好"：动作价值与优势不同，是教科书内容。
- W1-pure 在 ALFWorld 上退化为一个比特（`target_revealed` 占九成，P2 成立）；G 的 B1 0.84 用同任务兄弟的总成功率、完全不匹配状态即可达 0.838（deep §2.5）。

### 1.2 deep 分支后半段为什么不作主线

- 信息 × 执行因子实验：6 个手选点、每格 8 次，完整的"显现再缩小"路径只有 s005_t31 一个；机制依赖 ALFWorld 的持物规则，是环境细节而不是信用分配的一般规律。
- 实际 Hindsight teacher 探针的主假说没有得到支持：80 个 Live 点上 A − H = +0.66 pp [−0.39, 2.02]。
- 问题从"信用需要什么信息"漂到了"动作价值如何产生"。final_ruling_deepening_2026-10-27 §1 已指出过一次同样的偏离。

deep 的结果在 P4 中保留，但作为组件（见 1.5 的分叉三类），不作头条。论文初稿 v0.1（`papers/draft_2026-10-30/`）的主线若 P4 被采纳则不再沿用。

### 1.3 两个反常识结果

1. **熵不是关键性代理。** `entropy_q` 在 B1 上方向与先验相反（AUROC 0.44），在 B2 上归一化效应 −0.05 [−0.19, 0.09]（P1 不成立，D-049）；CARL 的分布层面效应 δ = 0.42 在本设置下为 0.06；E1 中 entropy-top-k 从不优于 uniform（k = 1 时 Fork 召回差值 CI [−0.024, 0.016]）。裸 prompt 熵与 32 草稿采样熵两种口径都试过。
2. **模型知道自己会不会失败，却不知道哪一步重要。** 隐状态探针 C_sel 在 B1 上 0.75、V 0.73（与 Doomed from the Start 一致），在 B2 上 C_sel 0.59（CI 下界 0.552 < shuffle 97.5% 分位 0.581，D-050）、V 0.51。

### 1.4 核心论点

**分叉出现在策略看不见的地方。** 若策略能从自身上下文判断哪个候选更好，它就会以较高概率选它；这样的点表现为 chosen 明显优于替代、且置信度与隐状态会反映出来。数据显示相反：

- 臂 A（−conf）在 13.1% 路由下召回 0.150，与 CWGT 的 chance 结论相容（M1 门）。
- Live 上 chosen-vs-mean 占动作间方差的 13.0% [10.1, 16.5]，不高于均匀随机锚点的期望 25%；CWGT 修订版 172 点上同一分解的 chosen 份额约 30%（替代内部 70.4% [53.2, 84.9]），区间同样覆盖 25%（deep §2.2）。即 chosen 在自己的候选集中没有系统性地处于更好的位置。
- 把缺失的位置信息补进上下文后，策略自己就消解了分叉：24 个原 Fork 点上，两臂差距从 44.3 pp 降到 7.3 pp，原弱分支 +38.3 pp [25.0, 51.6]；s026_t35 补齐后 16/16 次下一步直接走向目标位置（opportunity_completion_results_2026-10-28 §2–3）。

两个反常识结果因此是同一现象：熵衡量 Agent 有多迷茫，所以它指向 Dead；隐状态编码 Agent 知道什么，所以它预测结局，却不包含决定"哪个动作更好"的、Agent 尚不掌握的世界事实。

一句话：**内省信号能告诉你 Agent 是否已经迷路，不能告诉你哪一步本可以不迷路。**

形式上这接近 POMDP 中的信息价值，数学不新。新意在于：(a) 在有回放真值的 LLM Agent 上划出这条经验边界；(b) 它对一整类从策略自身提取信用的方法（熵选关键步、置信度加权、隐状态价值、看日志打分的 LLM judge、hindsight 自蒸馏）给出原则性的适用范围；(c) 它导出一个反直觉、可检验的规模预测（1.5 第 4 条）。

### 1.5 分叉三类与可证伪推论

按"决定哪个动作更好的东西卡在哪里"，分叉分三类：

| 类型 | 含义 | 已有证据（deep，探索性） | 谁原则上能找到 |
|---|---|---|---|
| 信息受限 | 决定好坏的世界事实不在上下文中 | 信息补齐：差距 44.3 → 7.3 pp | 只有与环境交互（一步 peek、回放） |
| 利用受限 | 事实在上下文中，但策略没有用上 | 同世界事实、逐字重复的子集仍有 +3.86 pp [1.02, 7.67]（Gold） | 原则上内省信号与更强的评判者可见 |
| 执行受限 | 下游执行瓶颈阻断收益 | 执行修复因子实验（6 点） | 需改变后续策略；不在 P4 主检验范围 |

可证伪推论：

1. 内省信号（−conf、熵、B_multi、C_sel、V）在信息受限层内对 Fork 无判别力，在利用受限层内有判别力。
2. 只看决策时上下文时，更强的评判者在利用受限分叉上能比 7B 挑出更好的动作，在信息受限分叉上不能（不超过常识先验）；给它带动作对应的一步反馈后，信息受限分叉上的选择显著改善。
3. 看完整 factual 日志（含终局奖励）的评判者，只有当日志的后续部分恰好揭示了决定性事实时，才在信息受限分叉上获益。
4. **模型越强，内省信用越差。** 更强的策略会消解利用受限分叉，剩下的分叉以信息受限为主，内省信号对 Fork 的判别力不升反降。

## 第二部分：定义（E0 时冻结）

### 2.1 分层

在 M0 的 Live 集 𝓛（n = 1,478）上，用 deep 分支 `exploratory_extract.py` 的逐点标记定义三层。标记只读 prompt、factual 历史、合法动作与 peek 文本，不读结局。目标实例 = 从任务描述抽取的目标物体在文本中出现的实例 ID（如 `knife 1`）。

| 层 | 条件 | 说明 |
|---|---|---|
| **I（信息受限候选）** | `prompt_target = False` ∧ `any_new_to_history = True` | 当前 prompt 中无目标实例，且至少一臂的一步响应引入了 factual 全历史（含合法动作）未出现过的目标实例 |
| **U（利用受限候选）** | `prompt_target = True` ∧ `any_target_mention = True` ∧ `any_new_to_history = False` | 当前 prompt（观察或合法动作列表）中已有目标实例，至少一臂的响应提及它，且没有任何臂引入新实例 |
| **N（无目标线索）** | `prompt_target = False` ∧ `any_target_mention = False` | prompt 中没有目标实例，任何臂的响应也不提 |
| 其余 | 不满足以上任一 | 只报告计数，不进检验 |

层是代理：只以目标物体为决定性事实。属性（冷/热/干净）与目标容器不在定义中，U 层因此会混入部分信息受限与执行受限的分叉；这使 E1 的检验偏保守（混入会缩小 U 与 I 的差）。

**一致性检查（E0）：** 在 main 上用新脚本重算标记后，层计数必须与 deep `exploratory_results.json` 的 `w1_subsets` 一致：I 层 Live 299 / Fork 184，U 层 Live 574 / Fork 202，N 层 Live 502 / Fork 65，其余 Live 103（27 + 39 + 37）。四者之和 1,478。不一致则停下写 DECISIONS。

### 2.2 信号

- **内省信号（状态级）：** 直接使用 M0 冻结的 out-of-fold 分数 `eval/scores_B2.parquet` 中的 `A(-conf)`、`single:entropy_q`、`single:entropy_sampled`、`B_multi`、`C_sel`、`V`。**不重新拟合**，不在层内调参。B+C 因 D-050 未修复，不使用。
- **内省信号（动作级）：** 策略在五臂上的候选分布 p_π(a) = softmax over 五臂 of `logp_sum`（`data/scores_fp32.parquet`，HF fp32 主口径，D-041）。
- **世界对照：** `W1pure_multi`、`single:target_revealed`；动作级为 deep 的"在响应提及目标的臂中均匀选，无则保留 chosen"规则（final_ruling_deepening §3）。
- **兄弟对照：** `G_multi`。

### 2.3 评估量

- **层内 B2：** 每层内 Fork(het) vs Indifferent 的 AUROC，按轨迹 cluster bootstrap 10,000 次；分层 shuffle 对照（层内、按轨迹内进度三分位，1,000 次）。层间差 AUROC_U − AUROC_I 在同一次轨迹 bootstrap 中同时重算两层得到 CI。
- **动作选择收益：** 对选择分布 p，J(p, q) = Σ_a p(a) q_a。G_u = J − mean_a q_a（相对均匀），G_c = J − q_chosen（相对 chosen）。**q 取库 1+2（6 次/臂）**：Fork 标签来自库 3–6，评估池与选点池不重叠；Gold（20 次/臂）覆盖的点作第二读出。
- **标签量（零模型，报告）：** 各层内 Credit-pivotal 点的 sign(A_3456) 正比例；各层内 chosen 对比占动作方差的份额（库 3–4 × 5–6 交叉乘积估计，同 deep §2.2）。

### E1 内省信号按层拆分（CPU，≈ 1 天，零新续跑）

- **做法：** 按 2.3 计算 2.2 全部信号在 I、U、N 三层的层内 B2，以及动作级 G_u、G_c（在各层 Fork 点上）；报告 2.3 的标签量。
- **脚本 / 产出：** `exploratory_P4/p4_e1_introspection.py` → `exploratory_P4/e1.json`（含脚本路径、commit、全部输入文件 SHA256，`CLAUDE.md` §9.9）。
- **预测：**
  - **P4-1：** 在 I 层，五个状态级内省信号的 AUROC 均不高于层内 shuffle 97.5% 分位。
  - **P4-2：** C_sel 或 B_multi 的 AUROC_U − AUROC_I 的 CI 不含 0 且为正。
  - **P4-3：** 策略候选分布的 G_u 在 I 层 Fork 上 CI 含 0，在 U 层 Fork 上 CI 不含 0 且为正。
  - **P4-4（标签量）：** U 层 Credit-pivotal 的 sign(A) 正比例高于 I 层；U 层 chosen 对比份额高于 I 层。

### E2 评判者实验（GPU，只打分，≈ 4–6 GPU 小时，零新续跑）

- **样本：** I 层与 U 层的全部 Live 点（873 点；主分析为其中 386 个 Fork 点），预先固定，不再筛选。
- **评判者：** Qwen2.5-7B-Instruct（与策略同一 checkpoint，`env/qwen_sha256.txt`）；Qwen2.5-32B-Instruct（bf16，单卡 96 GB 可放下；revision hash 运行前写 DECISIONS）。同一家族避免分词与模板差异；32B 同时是 E3 的策略。
- **条件：**

| 条件 | 评判者可见内容 |
|---|---|
| S | 决策时策略看到的原 prompt |
| L | S + 完整 factual 日志（每步回复、动作、观察）与终局奖励 |
| F | S + 五臂带动作对应的一步反馈（`data/peek_alts/`） |
| Fx | F 的相同内容，四个替代的反馈按固定 derangement 置换，factual 不变 |

  四种条件共用同一评判指令（"为该 Agent 选出最能提高任务完成概率的动作"）与同一五个候选命令。输入中不出现任何回放成功率、三域标签、Gold 或隐藏环境事实。
- **打分：** 在固定的回答前缀之后，对五个完整候选命令做 teacher-forced 打分（序列 logprob 之和，含结束标记），在五个候选上归一化得 p_judge；同时报告 argmax。沿用 teacher probe 的共享前缀打分与 fp32 词表投影，先在固定样例上与整序列直接打分核对（deep `teacher_probe_2026_10_29/NUMERICAL_NOTE.md`）。不使用 7B 实现的思考文本，两种评判者口径一致。
- **派生分层：** I 层内按 `future_reveals` = 1[任一臂所揭示的目标实例在 t 之后的 factual 观察中出现] 再分两组，用于 P4-7。
- **脚本 / 产出：** `exploratory_P4/p4_e2_judge_prepare.py`、`p4_e2_judge_score.py`、`p4_e2_analyze.py` → `exploratory_P4/e2.json`。
- **预测（均在 Fork 点上，读出 G_u，库 1+2；Gold 为第二读出）：**
  - **P4-5：** S 条件下，32B − 7B 的 G_u 差值在 U 层 CI 不含 0 且为正，在 I 层 CI 含 0；交互（U 层差值 − I 层差值）CI 不含 0 且为正。
  - **P4-6：** I 层上，两个评判者的 F − S 与 F − Fx 均 CI 不含 0 且为正。
  - **P4-7：** I 层上，L − S 仅在 `future_reveals = 1` 组 CI 不含 0 且为正；在 `future_reveals = 0` 组 CI 含 0。
- **注意：** 常识先验（"刀常在抽屉里"）会让评判者在 I 层也有一部分收益。P4-5 比较的是 32B 相对 7B 的增量，不是相对均匀的绝对水平；7B 自身的 S 条件即先验基线。

### E3 策略规模复制（GPU，≈ 3–4 GPU 天；仅在 §4 判定为 R-BLIND 或 R-BLIND-7B 时执行）

## 第四部分：判定（E0 冻结后不改）

按表序取第一个满足者。

| 读法 | 条件 | 含义与后续 |
|---|---|---|
| **R-NULL** | P4-6 在两个评判者上都不成立 | 一步反馈对评判者无用，世界信息通道本身不成立；停止 P4，论文回到 M0 的 R-WORLD 叙事 |
| **R-PRIOR** | P4-5 的交互 CI 含 0，且 32B 在 I 层 S 条件下 G_u 显著为正 | 常识先验即可消解信息受限分叉；核心论点不成立；论文改用"两次压缩"框架（10-30 会话第一版骨架），不做 E3 |
| **R-BLIND** | P4-1、P4-2、P4-5、P4-6 均成立，正对照成立 | 论点成立；执行 E3；论文主线采用 P4 |
| **R-BLIND-7B** | P4-1 成立、P4-2 不成立（内省信号在 I、U 两层都无判别力），P4-5、P4-6 成立 | 7B 连可见信息都未反映在内省信号里，但更强的模型能利用；论点改述为"内省信号的可见范围随能力扩大，但不覆盖信息受限分叉"；E3 成为关键证据，执行 |
| **R-MIXED** | 其余情形，或 E1 正对照失败 | 全部照报，不执行 E3，交研究者裁决 |

## 第七部分：风险与不能说的话

**风险：**
- 层是以目标物体为唯一决定性事实的代理，U 层混入其他类型，可能冲淡 P4-2。
- 32B 与 7B 只构成一对模型，"规模"结论只能写成该对模型上的观察。
- E2 的评判者打分是固定候选集上的条件概率，不是自由生成的动作边际。
- E1 用的 out-of-fold 分数是在全体 Live 上拟合的，层内表现可能受拟合时层间混合的影响；这是保守方向（全体拟合会学到层间差异，而层内 AUROC 剔除了它）。

**不能说：**
- 内省信号"原则上不可能"找到分叉（只能说在信息受限层内未检出）。
- 新的理论贡献（信息价值、POMDP 是已有框架）。
- "更强的模型自评更差"作为一般规律（E3 只有一对模型）。
- 执行受限分叉已被解释（P4 不检验）。
