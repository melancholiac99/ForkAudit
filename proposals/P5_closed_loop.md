## 第二部分：论点

**主论点：** LLM Agent 的步级信用首先是一个信息问题，而不是估计问题。在决定结局的分叉上，决定性的世界事实不在 Agent 的上下文中；从 Agent 自身上下文算出的信号（置信度、熵、隐状态、它自己的动作偏好）在这些点上不比随机好；一步、带动作对应的世界反馈能拿回回放价值的大部分；以它为步级信用，能以远低于回放的成本改进学习。

**论文的三个贡献（对应审稿人会问的"是什么、为什么、所以呢"）：**
1. **诊断：** 在有回放真值、预注册的审计中，内省信号的失败被定位到信息受限分叉；熵指向"已经迷路"（Dead），而不是"哪一步重要"。
2. **机制：** 失败是信息性的而非能力性的——补齐事实即消解分叉（第 7 条）；更强的评判者只看上下文无法替代信息（E2，待验证）。
3. **闭环：** 反馈锚定的步级信用在同等成本下改进学习，优于回放信用与熵选点的回放信用（E4，待验证），并在第二环境复现（E5）。

**按结果调整的表述：**

| P4-X 读法 | E2 读法 | 第 5 条与贡献 2 的写法 |
|---|---|---|
| R-X-MISDIRECT / R-X-UNDEREXPLORE | E2 中 32B 只看上下文在 I 层不优于 7B，加反馈后显著提升 | 最强版："在最需要信息的步上，Agent 的偏好背离信息（或不足以探索）；更大的模型也无法凭推理弥补" |
| R-X-DILUTION / R-X-ARTIFACT | 同上 | "Agent 在信息受限分叉上是盲的（偏好 ≈ 随机）"；不写"背离" |
| 任意 | R-PRIOR | 常识先验能部分替代信息：报告它弥补了多少，反馈仍是主来源时论点保留，否则降为"两类来源互补" |
| 任意 | R-NULL（评判者用不上反馈） | 信息通道只在规则读取下成立；E4 改用规则标注，E5 的规则需在看数据前定义；通用性论证减弱 |

### 3.3 E4：闭环学习实验（新增；GPU ≈ 3–4 天）

**问题：** 在不做回放的前提下，用一步带对应的反馈给步级信用，同等成本下能否比回放信用、熵选点的回放信用、通用探索启发式与只用结局的训练，更好地改进策略？

**任务与划分：**
- 训练游戏：ALFWorld train split，**排除 M0 的 100 个任务**，按六类任务分层抽 400 个，固定种子，列表先冻结提交。
- 评估：`valid_seen`（140）与 `valid_unseen`（134），任何选择与调参都不使用。
- 策略、模板、温度 0.7、50 步、两轮历史与 M0 相同。

**采集：** 每个训练游戏一条 on-policy 轨迹。在"搜索阶段"的步上（forward 规则：当前 prompt 中没有任务目标物体的实例，即 P4 分层中 `prompt_target = False`），按 M0 的方法采草稿、取四个不同替代。每个替代保留产生它的那份完整草稿文本（含 `<think>`），作为偏好对中的回复。

**臂（都输出步级偏好对：同一 prompt，偏好回复 ≻ 不偏好回复）：**

| 臂 | 选点 | 标注 | 说明 |
|---|---|---|---|
| **A 反馈锚定（评判者）** | 全部搜索阶段步 | 五臂各执行一步；7B 评判者在 E2 的 F 条件模板下选最优臂；最优 ≠ chosen 时，最优 ≻ chosen | 主方法；若 E2 为 R-NULL，改用 A′ 为主 |
| **A′ 反馈锚定（规则）** | 同 A | 一步反馈提及目标实例的臂 ≻ chosen（chosen 未提及时） | 最简版本，即 E1 的世界规则 |
| **B 回放信用** | 搜索阶段步中均匀抽，点数按成本匹配 | 每臂续跑 3 次到终局得 q̂；q̂ 最高 ≻ 最低，差 ≥ 1/3 时成对 | 强对照，代表"花钱买真值" |
| **C 熵选点回放** | 同 B 的点数，按 `entropy_q` 取最高者 | 同 B | CARL / 熵选分叉点类做法 |
| **D 探索启发式** | 同 A | chosen 为非探索类（P4-X 的 N̄ 类）时，随机一个探索类（E 类）臂 ≻ chosen | 排除"只是学会了多探索、少循环" |
| **E 只用结局** | — | 对成功轨迹的步做 SFT（拒绝采样微调），梯度 token 数与 A 匹配 | 结局级基线 |
| **F 不训练** | — | — | 基线 |

**成本匹配：** 主口径为策略生成调用数（采草稿、续跑、评判者前向均计入），环境步数并列报告。B、C 的点数由"与 A 同等生成调用数"反推。另报一个"偏好对数匹配"版本（A 下采样到 B 的对数），区分"对更准"与"对更多"。

**训练：** LoRA（r = 16，α = 32，全部线性层），DPO（β = 0.1），2 个 epoch，学习率 5e-6。学习率只在训练集内留出的 40 个游戏上、用 A′ 调一次，所有臂共用。每臂 3 个训练种子。

**评估：** 两个验证集上每游戏 1 条轨迹（T = 0.7）× 3 个评估种子，贪心解码作敏感性。主指标为成功率，按游戏配对、按游戏 cluster bootstrap。附加诊断：训练后的策略在 M0 的 I 层 Fork 点上对五臂的候选分布，用已有 q 计算 G_u，检验训练是否修正了第 5 条描述的现象。

**预测：**
- **PL-1：** A（或 A′）在 `valid_unseen` 上成功率高于 F，配对差 CI 不含 0。
- **PL-2：** 同等成本下，A 相对 B 的配对差 CI 下界 > −2 pp（非劣），且 A 优于 C（CI 不含 0）。
- **PL-3：** A 优于 D（CI 不含 0）。
- **PL-4：** A 训练后在 M0 I 层 Fork 上的 G_u 高于 F。

**读法：**

| 读法 | 条件 | 含义 |
|---|---|---|
| **R-L-WIN** | PL-1、PL-2、PL-3 成立 | 闭环成立，论文按方法加机制投稿 |
| **R-L-HEURISTIC** | PL-1 成立、PL-3 不成立 | 收益来自通用探索，不是信用；贡献 3 降为"信息诊断能指导出简单有效的训练信号"，需诚实写明 |
| **R-L-COSTLY** | PL-1 成立、PL-2 不成立 | 反馈信用有效但不如回放划算；论文改为测量 + 成本权衡 |
| **R-L-NULL** | PL-1 不成立 | 闭环不成立；论文降为分析论文（贡献 1、2），考虑 TMLR 或 D&B 方向 |

**成本估算：** 采集（400 游戏 × 约 30 步 × 32 草稿，加一步 peek 与评判者打分）约 1 天；B、C 的回放受成本匹配约束，与 A 同量级；训练 7 臂 × 3 种子 × 约 1 h；评估 274 游戏 × 3 种子 × 19 个模型约 1–1.5 天。单卡 96 GB 合计约 3–4 天。

### 3.4 E5：WebShop 复现（GPU ≈ 4–6 天）

**原则：** 把 ALFWorld 上的探索性发现，在 WebShop 上作为**确认性检验**预注册，并在看任何 WebShop 结局之前冻结全部定义。

- **流程：** 100 个任务；库 1–2 覆盖全部可定义点，库 3–6 只覆盖 Live；一步 peek；协议与 M0 一致。
- **决定性事实（看数据前冻结）：** 指令要求的属性（选项、类别、价格上限）。**I 类比：** 当前页面没有满足全部硬性属性的商品，且至少一臂的一步页面出现了这样的商品。**U 类比：** 当前页面已经出现。
- **复现目标：**
  1. 三域比例与 Masked 份额；
  2. 内省信号在轨迹内不过 shuffle；
  3. I 类比层上，策略候选分布的 G_u ≤ 0，规则读取的反馈与 7B 评判者（F 条件）的 G_u 显著为正；
  4. E4 的精简版：A、D、F 三臂，2 个种子。
- **读法：** 1–3 全部复现 → 论点跨环境成立；只复现 3 → 写"机制复现、结构比例环境相关"；3 不复现 → 论文限定为 ALFWorld，并调低投稿目标。

### 10.2 主论点修订

**信息受限分叉上的步级信用由信息决定，而不是由评判者能力决定。** 三个层次的证据：
1. 定位：内省信号不定位分叉（M0）。
2. 选择：无世界反馈时，任何规模的评判者都把概率从新地方挪开；更大的模型只在事实已在上下文中时更好；事后日志几乎无用并锚定已执行动作。一步带对应的反馈恢复大部分价值，更强的模型把它用得更好（能力与信息互补）。
3. 机制（待 E2-M 确认）：缺少自身历史使常识先验变成误导；缺少世界事实使所有选项看起来一样。
