前向信息 × 事后信用：瓶颈诊断与最小修正方案
评估日期： 2026-10-22　评估对象： 《从前向决策信息到事后信用估计：完整研究构思演进记录》
文件性质： 研究合作者意见。所有"概率""置信度"都是主观估计，用来比较路线，不是承诺。
0. 结论先行
核心命题值得保留，但当前实验路线有一个已经可以证实的结构性缺陷。 你计划采集的 F1（候选动作分布）、F2（事前预期 / Belief Probe）、F3（来源与依赖）以及隐状态，在标准 on-policy 管线里全部可以由"逐轮完整输入 + 旧策略权重"在 rollout 结束后精确重算。因此无论它们对信用多有用，这条路线都无法证明"前向记录"有信息增益，最多只能证明"事后没有用好"——而"没用好"这一侧已经被 Prospective Hindsight（NeurIPS 2026）和 EMPG（ICML 2026）占位，并且 Credit Without Ground Truth（2608.19760）在 ALFWorld 上对策略置信度、outcome-conditioned logprob 比值和 LLM judge 给出了负结果。这就是项目反复卡住的根源（见 §1）。

最小修正（属于 reframe，不是换题）：
1. 把命题里的"没有被记录"改成"在声明的访问条件下无法被恢复"。
2. 把主角信号从"模型内部的犹豫"移到"决策时刻、未选动作在世界中会得到的反馈"。具体做法记为 W1：在执行时对 k 个未选的可执行动作做一步、对 Agent 隐藏的 peek，并把结果记下来。
3. 模型侧信号（F1/F2）降级为对照阶梯中的一级。
4. 用一个"信息阶梯"实验，在高信度的 replay 信用上测量每类信息能解释多少信用方差、值多少次 rollout。
W1 可以直接从计算参考信用时替代动作分支的第一步观察中取得，几乎零额外成本。

这与我今天早些时候给出的方向（可恢复性 reframe + 信息阶梯）一致。本次独立复核补充了四点：一是新核查到的 CRR（NeurIPS 2026）和 C3 等工作；二是把"同组兄弟轨迹"列为必须的强基线；三是吸取 2608.19760 的教训，对参考信用信度提出具体要求；四是发现 W1 可以零成本嵌入参考信用计算。
1. 为什么卡住：我最认可的解释
回看演进记录，有一个反复出现的循环：
1. 提出想法，落到一个具体设计；
2. 遭遇同一类反驳：这是上下文工程（C6、C10），这可以重算（J1 反驳 2），这已经是 PH/EMPG（J1 反驳 3）；
3. 换一个容器继续：资格迹 → 依赖图 → Scanner → 各种 E1 → F1/F2/F3。
容器换了很多次，但每次被撞的是同一堵墙。

这堵墙来自"前向信息"这个概念本身。它把两类可恢复性完全不同的信息放在了一起。

模型侧信息包括候选动作分布、犹豫或确定、事前预期、Probe 的回答、残差流表征。对 LLM 来说，它们都是"输入 token 序列 + 权重"的确定性函数。你在 C8 已经核实 AgentOPSD 会保存逐轮实际输入 token；on-policy 训练时 θ_old 必然在场，trainer 本身就要用它重算 old_log_prob。所以这些量在 rollout 结束后可以逐位重算。
- Re-feeding Is Not Replaying（2606.15621）实测：在 vLLM 的 batch-invariant kernel 下，重喂前缀与恢复原始解码状态在所有测量通道上完全一致；只有在 batch-variant kernel 下，才出现近似零均值的扰动。需要注意，这是单一任务族（GSM8K）、单一引擎版本上的测量，所以 §4.5 安排了你自己的核验。
- C3（2603.06859）的标题就叫 The Trace Is the State。
"在反馈之前做预测"也不构成例外。Probe 是否"事前"，是由条件集决定的，不是由墙钟时间决定的：事后把 (x_t, a_t) 喂给同一个 θ_old，模型同样看不到反馈。

世界侧信息指环境对"没走的那条路"会给出的反馈，以及 Agent 没有观察到的环境状态。如果环境不能回放（真实网页、在线 API、与人交互），它在 rollout 结束时就永久消失。即使环境能回放，也要付出重跑的代价。

你在 C10 的那句话——"将多种可能结果收敛为一条实际执行路径"——说得很准。但这次"收敛"真正不可逆地丢掉的是世界侧部分：世界对其他可能性的回应。策略对各种可能性的权重（模型侧）并没有丢，它还在 θ_old 里。

你此前的具体例子都落在模型侧：犹豫/确定、候选偏好、C10 的三动作两策略表、Belief Probe。所以每个具体方案都会撞上"重算基线"。

你在 G2 写下的最优风险差公式可以把这一点说得很精确：

\(\mathcal E^*(L,R)-\mathcal E^*(L,R,F)=\mathbb E\big[(\mathbb E[C\mid L,R,F]-\mathbb E[C\mid L,R])^2\big].\)

只要条件集里包含 θ_old，并且 F = f(L, θ_old)，这个差就恒等于 0。对 W1 这类世界侧信息，它才有可能为正。

可能推翻这个解释的证据：
- E0 发现现实中主流管线并不保留 θ_old 或逐轮完整输入。例如异步 RL 用陈旧策略生成数据且不留检查点，或者离线数据来自闭源 API 模型。在那些场景里，模型侧信息确实不可恢复，你原来的主角就重新成立（见 §3.4 备选 B）。
- 在 batch-invariant 设置下，运行时记录的 F1 与事后重算存在系统性（而非零均值）差异。

关于你在 G3 担心的"定义性优势"，可以补一个简单的事实：

\(|A^\pi(s,a_t)| \le \big(1-\pi(a_t\mid s)\big)\,(Q_{\max}-Q_{\min}).\)

在二值回报下，右边就是 1 − π(a_t|s)。所以候选分布只约束了 policy-relative 信用的幅度上界，并不携带符号信息，也不携带 Q(s,a′) 的信息。这正是 F1 在固定替代对比上大概率帮不上忙的原因。
3. 修正方案：从"没有被记录"到"无法被恢复"
3.1 命题改写
原命题（D 节）： 执行时存在训练日志没有保存的、与信用相关的信息；补存它能改善事后信用。

新命题： 在声明的访问模型下——是否保留 θ_old、能否回放环境、回放预算多大——执行过程中存在事后无法恢复的、与信用相关的信息。它主要位于世界侧，即未选动作的即时反馈。在执行时以低成本保留它，可以改善 rollout 完成后的步级信用估计，而且它的价值可以用"等价 rollout 数"计价。

由此得到三条可检验假设：
- H1′（可恢复性）： 模型侧前向信号 ⊆ σ(L_real, θ_old)。在此条件下，"记录"它们的信息价值为 0，只剩"利用"价值。检验方式是一个命题加一个 1 天实验。
- H2′（信息位置）： 在高信度 replay 信用上，W1 相对 L_real + 模型侧 M + 同组兄弟 G 有显著的条件增量，并且增量集中在覆盖空洞（单例状态、低熵状态）。
- H3′（计价）： W1 的 rollout 等价价值（REV）≥ 2，而它的成本只是每个节点 k 次环境步。
保留不变的部分：
- 事后（rollout 完成后）的估计器定义；
- "执行时多保留信息"的结构；
- 图只作容器——W1 只是节点属性，你的 forward_evidence_recorder.py 可以直接改造来存它；
- 第一阶段不训练；
- E0；
- 用 replay 作为独立参考信用；
- L vs L+F 的比较框架。
改动的部分：
- 主角信号换成 W1；
- F1/F2 降为对照级；
- F3 不再单列，因为它本质上是对 L 的事后结构化；
- 新增同组基线 G；
- E2 和 E3 合并成一个实验。
3.2 这还是你的题目吗？——逐条对照你划下的边界
先说结论：是 reframe，但主角确实换了，这一点需要你自己拍板。

第一，它延续了 C10 的核心直觉。"可能性压缩为路径"时丢掉了两样东西：策略对各可能性的权重（可恢复），以及世界对各可能性的回应（不可恢复）。新主角就是后者。

第二，它落在你 E2 节已经认可的范畴里。你把前向采集分成"被动读数 / 主动诊断 / 额外因果探测"。W1 就是"额外因果探测"的世界侧版本：主动执行、对 Agent 隐藏、只记录、不改变原 Agent 的动作分布——在 fork 出的环境副本里执行，或者执行只读动作。

第三，它尊重你在 F 表里划的边界："未打开箱子的隐藏环境真值不是 Agent 当时可获得的前向决策信息"。W1 只包含Agent 在那一刻用自己的合法动作就能触达的观察。特权环境状态 W0 只作为诊断天花板出现，永远不作为方法提出。

第四，变化在这里：故事的主角不再是"Agent 内部的犹豫"。如果你认为内部犹豫才是不可替代的核心，请看 §3.4 的备选 B，并接受它更低的预期回报。
3.3 定位：夹在两篇 2026 工作之间的空白
CRR（2609.33875，NeurIPS 2026）证明：在可 fork 的 SWE 环境里，于选定决策点恢复状态、采样替代动作并滚到终点，可以得到步级回报对比；同等墙钟下，SWE-bench Verified 上比延长的 GRPO 高 5 个点。它在摘要里把"负担得起、可靠的状态恢复"列为适用前提，把昂贵或不完美的回放列为局限。

2608.19760 证明：不做回放的廉价信号，在回放真值面前不比洗牌对照好。

两者之间的问题没有人回答：事后无法或无力 fork 时，执行当下应该留住什么？它能买回多少回放信用？ 你的论文就回答这个问题。

综述 2604.09459 在"部分可观测"和"有限回放"两项诊断下，只要求做"特权状态审计"和"声明回放来源与噪声底"，没有给出"该记什么、值多少"的测量。这也是一个可以直接引用的空白。

这个定位还顺带回应了 J1 的反驳 1、2、3：
- 反驳 1（丢信息不新）：你不是在说"有信息丢了"，而是在测"哪一类、值多少"。
- 反驳 2（可重算）：你主动把可重算的部分划出去，并用实验证明它可重算。
- 反驳 3（PH/EMPG 已做）：你把 PH/EMPG 式信号放进阶梯，当作对照。
3.4 备选路线
备选 B（保留模型侧为主角）： 只在模型侧真正不可恢复的场景里成立，也就是行为策略事后不可得的场景：
- 由闭源 API 模型生成的离线 Agent 轨迹；
- 用陈旧策略生成数据且不留检查点的异步 RL；
- 多模型拼接的管线。
要检验的问题是：生成时记录 top-k 决策分布，能否改善离线信用或优势估计？鉴于 §2 第 5 条，我对它的预期回报低于主线。

备选 C（主线失败时的退路）： 写一篇"步级信用不确定性分解"的分析论文，主要发现是"后续策略随机性占主导"，并讨论对 replay 和价值模型投入的含义。更适合 TMLR、workshop，或者附带公开数据去投 NeurIPS Datasets & Benchmarks。
4. 决定性实验：信息阶梯（约 4 周，2026-11-24 判定）
设计原则： 只做一次昂贵测量，也就是参考信用；其余各级信息都在这份测量上做廉价分析。无论结果正负，都能区分 §2 中的几种解释。

R6 = R3 + B_m    预算为 m ∈ {1, 2, 4, 8} 的回放    需要回放    m 条续跑    计价轴，用于计算 REV


关键的省钱点：在 ALFWorld 这样的确定性环境里，替代臂续跑的第一步观察就是 W1。它是 (s, a′) 的确定函数，不携带续跑结局的噪声，可以零成本取出，不会泄露 C_ref。
4.3 估计器、对照与指标
估计器只用两族，避免过度设计。

第一族是岭回归。特征是少量、预先注册的通用标量特征：M 级的分布统计量、GraphHCA 成功势，以及由固定 LLM 给 peek 观察打出的"进展价值分"。不使用 ALFWorld 专用模板——这正是你在 B1 节否定过的做法。交叉验证按任务分 5 折。

第二族是固定的 LLM judge。所有级别使用同一模板，只改变可见信息。它检验的是"现有事后估计器能不能用上这些信息"。

对照有三种：
1. 边际保持的洗牌对照，与 2608.19760 相同；
2. 给 judge 补充等长填充文本，排除"只是多给了 token"的解释；
3. 任务内 peek 错配：把 W1 换成同任务其他节点的 peek。这是最强的对照——同类文本、错误配对。
指标有四个：
1. 交叉验证的增量 R²（ΔR²_cv）。用配对误差差做任务聚类 bootstrap，再除以 split-half 信度做衰减校正。
2. 关键节点（|C_ref| 超过 2 倍标准误）上的符号准确率。
3. REV（rollout 等价价值）： 使某一级的误差不再优于纯回放估计器的最小 m。它把"可重算信息"和"不可恢复信息"放到同一把以算力计价的尺子上。
4. 以上三项都按覆盖程度和策略熵分层报告。
统计功效（解析近似）： 下文所有 ΔR² 阈值都指衰减校正后的值，即占"可靠信用方差"的比例。设 W1 的真实增量为可靠信用方差的 8%、参考信用信度约 0.6，则观测尺度上的增量约 0.05。以 4 个新增特征做嵌套 F 检验，Patnaik 近似给出的功效约为：n=250 时 0.85，n=300 时 0.9。扣除交叉验证与任务聚类的损失后，我估计"CI 下界 > 0"的实际功效约为 0.7–0.8。所以 250 是下限，300 是推荐值。改用（节点, 替代动作）对为单位，会进一步提高有效样本量。

（我本想用蒙特卡洛模拟核对这组功效数字，但这次会话的沙盒没有成功启动。上面是解析近似，pilot 之后应当用真实方差重算一遍。）

5. PASS 时的论文骨架
暂定题目： What a Rollout Cannot Remember: Locating the Credit-Relevant Information Lost Between Agent Execution and Hindsight

贡献一：一个可恢复性视角。 用声明的访问模型，把"前向信息"拆成可重算部分与不可恢复部分。配合可恢复性命题、|A^π| 的幅度上界，以及 1 天的重算核验，把"日志丢了什么"从直觉变成可检验的分类。

贡献二：在两个环境上的系统测量。 测清"信用信息在哪里"：模型侧、同组、世界侧、特权状态、后续策略随机性各占多少。全部以 REV 计价，并揭示"覆盖空洞"机制。

贡献三：一个可直接落地的执行时记录协议。 用 peek 换回 X% 的回放信用，成本只占 Y%。同时公开数据。

可选贡献四： 小规模训练演示，匹配有效样本量。

6. 对演进记录 N 节八个问题的逐条回答
1. 问题定义。 有价值，但现在的表述既太宽又已被部分占位。"执行时信息比日志丰富"本身是平凡的，它的理论形式也已发表（§2 第 2 条）。界定清楚的版本是：在声明的访问模型下，哪些执行时信息不可恢复？它解释了多少可靠测得的步级反事实信用方差？折合多少次 rollout？

2. 已有工作覆盖与最危险的重叠。 最危险的是两件事的叠加：PH（F2 的训练用法，NeurIPS 2026）加上 2608.19760（ALFWorld 回放审计 + 模型侧信号负结果）。二者合起来，使"模型侧为主角"几乎无法发表。其次是：
- CRR：fork 取步级对比，NeurIPS 2026；
- 综述命题 2 与 2609.30734：不可识别性理论；
- GraphHCA 与 GiGPO：同组汇聚的事后信用。
尚未被覆盖的是：信用信息位置的实证分解，以及"不能 fork 时该留什么"。

3. 最有希望的代表性信号。 决策时刻未选合法动作的即时世界反馈，即 W1。模型侧候选分布最多提供幅度上界（§2 末尾的不等式），我不建议再寻找"更好的模型侧变量"。

4. F2 Probe 的采集忠实性。 这个问题在新框架下会自动消解。Probe 是 (x_t, θ) 的确定函数，事后重算结果相同，所以根本不需要声称它"读出了原决策的隐藏信念"。只需要把它命名为"同一模型的条件查询"，并只评价它的预测价值。

5. 基线公平性。 每个估计器都要显式声明访问模型，可以借用综述的 CA-ID Card。公平的事后基线应当拥有：L_real、θ_old 重算、同组兄弟轨迹，以及作为计价轴的预算回放。在"不可回放"访问模型下，禁止任何回放；特权状态只作诊断。所有比较都在同一 REV 尺子上进行。

6. 参考信用如何可靠估计。 要点有五个：
- 每臂至少 16 次续跑，自适应加到 32 次；
- 用 split-half 信度和 Spearman–Brown 校正给出噪声天花板；
- 用 CRN 降方差，同时报告独立种子版本；
- 过采样非退化节点；
- 报告可测节点的覆盖率，并用哈希验证重放的确定性。
7. 顶会增量门槛。 只有"日志审计 + 信用预测改善"不够。至少还需要：
- 一个机制性发现，比如覆盖空洞，或"信用信息主要在世界侧"；
- 一个可复用的测量工具，即阶梯 + REV + 公开数据；
- 最好再有一个匹配有效剂量的小训练演示。
不需要理论下界。可恢复性命题加幅度上界作为框架就足够了。

8. 一个月、有限 GPU 下的最小决定性实验。 就是 §4 的信息阶梯：约 300 个节点，冻结 Qwen2.5-7B，GPU 需求约为数个 GPU·天。正反两种结果都能直接决定下一步。
7. 明确不建议做的事
- 不要按原计划先建完整的 F1/F2/F3 记录器，再跑 200 条带 Probe 的轨迹。那套数据在重算基线下证明不了你想证明的东西。
- 不要再花时间构造不可辨识性反例，直接引用综述命题 2。
- 不要依赖 AgentOPSD 的 trainer。冻结策略阶段用独立的 rollout 脚本更省事；E0 只需要它的数据结构做静态审计。
- 不要把特权状态 W0 包装成方法，否则会与你自己划的边界、以及 privileged critic 一族工作（SWEET-RL 等）正面冲突。
- 判定之前不要设计 RL 优化器。
- 除非判定结果很强，不要冲 ICML 2027。
8. 什么证据会改变我的判断
- 若 E0 显示主流管线并不保留逐轮输入或 θ_old（例如异步或离线设定成为常态）：模型侧信息在该设定下确实不可恢复，备选 B 升为主线。
- 若 batch-invariant 设置下运行时 F1 与重算 F1 仍有系统差异：§2 第 1 条降级为"近似可恢复"，需要重新评估模型侧记录的价值。
- 若阶梯中 M ≥ W1：模型侧回到主角位置，但必须采用"可重算、未被利用"的叙事。
- 若 pilot 中参考信用信度很低：步级对比不是好目标，应改为子目标级。
- 若有人先发表了"执行时 peek + 事后信用"的阶梯式测量：转向真正不可回放环境中的验证，或者转向"自信的系统性错误"这一切片。
