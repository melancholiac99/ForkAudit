## 1. 短分支汇合检验（S4，深度轴）

- **做法：** 从 factual 和各替代出发，让策略只走 h 步（h ∈ {1, 2, 3, 5}），看分支是否重新汇合到同一个与目标相关的状态，例如同一位置、同一物品栏、同一已揭示信息。h = 1 即 W1 peek，h → 终局即完整回放。
- **为什么值得做：**
  1. Q(s,a) = V(T(s,a)) 推广到 Q = E[V(Tʰ)]，可以直接回答"要往前看多深"。REV 从一维（续跑次数 m）变成二维（深度 h × 次数 m）。
  2. 不需要价值函数，是非参数的；同时覆盖信息揭示、预算浪费、行为锁定三种机制。
- **可零 GPU 离线做：** 库 1–2 的续跑存了动作序列，环境又是确定性的，在 CPU 上重放即可还原前 h 步的状态。特征取自库 1–2，标签取自库 3–6，两边不重叠。约 16 CPU 小时，需要 22 核模式。
- **风险：**
  - 与 BiPACE（bisimulation）相近，要查新。
  - "汇合"的判据（文本精确匹配，还是目标相关字段匹配）要预先定死。

## 2. E1 的自适应回放基线

- **问题：** B2 连回放自己都难过（库 1+2 每臂 6 次只有 0.66）。如果 E1 只和固定分配的回放比，审稿人会问"为什么不按点自适应地分配续跑"。
- **做法：** 分轮分配续跑：全败或各臂无差别的点提前停止，有差别的点继续加。这是序贯检验或多臂老虎机里找最优臂的标准做法。
- **定位：** 作为最强的回放对手（基线），不是贡献。
- **离线模拟：** 从库 1–4 存档中按顺序抽结果，标签用库 5–6 与 gold。每臂最多 12 次是模拟的上限。

## 3. 策略强度复制

- **问题：** 研究动机是"RL 训练后的 Agent 成功率已经很高"，但本文用的是成功率约 0.38 的基础策略。
- **预期影响：** 策略变强后，Dead 会从"必败"变成"必胜"，Pivotal 会变成少数犯错的点，"能否恢复"会更关键。三域比例和分叉机制都可能变化。
- **建议：** 至少找一个训练过的 checkpoint（公开的 GiGPO/verl-agent ALFWorld 7B，若有）做缩减设计的复制：100 条轨迹、库 1–2、gold 子集。
