# Hindsight Judges Defend What Was Done — 实验一预执行协议 v1

**状态：前瞻性、未产生本实验 GPU 数据。** 本文件依据 P4/E2 已知的探索性结果写成。若在新实验运行前要改动，请提交新版本；实验运行后不得回头改主指标或分组。

## 研究问题与现有证据

- **A：已观察（探索性）。** 完整事后日志 L 相比同一状态的完整决策前历史 M，抬高原策略实际执行动作的概率。
- **C：已有价值损害迹象（探索性）。** 在事实动作劣于替代动作的 P4 Fork 上，32B 的 L−M 价值变化对独立 q3456/Gold 可为负。
- **B：本实验测试。** 固定候选与对称的一步反馈 F，只更换被称为“原策略已执行”的候选编号，是否造成可测的偏好偏移和判断价值损害？
- **D：本实验不测试。** 此偏移若用于对事实动作直接授予训练奖励，是否导致自我确认学习？需后续单独训练实验。

不能把 P4 的 L−M 因果归为动作身份，因为 L 同时添加了 CoT、未来轨迹及最终奖励。原研究者上传的 `exploratory/anchoring_reanalysis.py` 是事后分析。其 P4 部分用 q12 分类、独立 q3456/Gold 评估；E4 只作回放噪声较高的探索性桥接，绝非新的因果检验。

## 样本及输入完整性

- **ALFWorld P4 E2**：I/U 层、Live 且 Fork，共固定 **386 点**（I=184、U=202），源 `exploratory_P4/strata.parquet`。
- 每点五个候选：`actions[0]` 为真实执行动作，`actions[1:]` 为四个候选替代；原 `S`（决策时 prompt）及 `F`（S + 五臂对称、动作—观察已对齐的一步反馈）直接复用 `e2_requests.jsonl.gz`，不更改候选或反馈。
- `e2_point_audit.json` 中候选在提示文本的显示顺序为随机排列。`actions[0]` **不是必然候选 1**。标签编号严格为 `display_order.index(arm)+1`（1-based）。
- 替代臂由原 `exploratory_arms.parquet` 的 **q12 最高替代臂**确定，并列取最小臂号；只用旧 bank 1–2 的 q12 做选择及质量分层。价值评价用独立 bank 3–6 的 **q3456**，另用 **Gold** 子集。不得以 q12 直接评估选择出来的同一替代臂。
- arms 来自 `research/deep-discovery-2026-10-27`；SHA 必须和原 `exploratory_P4/e2.json` 登记值一致。不得在看新结果后改对比臂。

## 固定处理组（386 × 10 = 3,860 次评判请求）

| S（无额外反馈） | F（五候选对称一步反馈） | 唯一变化 |
|---|---|---|
| `S0` | `F0` | 完全复刻原 S/F 文本，在**本次同机重新评分** |
| `SE` | `FE` | 只加元数据：“原策略实际执行了候选编号 N”，N 映射事实动作 |
| `SX` | `FX` | 上述元数据中只改数字 N，让它指向 q12 最优替代动作 |
| `SPE` | `FPE` | 事实动作编号的**人工标记**；明确说明不是真实执行记录 |
| `SPX` | `FPX` | 替代动作编号的人工标记；与 PE 只差数字 |

E/X 的背景语句完全一致，只变展示编号；PE/PX 也一样。F 的原始反馈、其他上下文和 candidate 序列必须逐字保留。身份标签不重复候选动作字符串，避免重复计数式 copy 偏差。人工标记的语义是“不是事实执行记录”；**因对比臂由 q12 选定，不能称人工标签是真正独立于动作价值的随机抽样。**

这里只操纵新生成的**元数据句子**，不直接篡改原 L 事实动作与环境反馈的对应关系。若标签干预为零，不能宣称 L 的后验偏好现象不存在；后续再测试 CoT、日志角色、截断以及对称双分支完整日志。

## 主终点与统计（预先确定）

`p_c(a|s)`：与 P4 原协议相同的 BF16/FP32 评分后端计算五个候选完整回答序列的 log-prob-sum，对五臂做温度 1 softmax。事实臂 `f=0`，q12 最优替代臂 `b`。

**主要因果终点：F 全部 386 个 Fork 的身份切换效应**：

\[
D_{id}(s)=\tfrac12\big([p_{FE}(f)-p_{FX}(f)]+[p_{FX}(b)-p_{FE}(b)]\big).
\]

全部点按轨迹聚类 bootstrap **4,000 次**，固定 seed=20261102。只有均值 95% CI 下界 > 0，才判断“在 F 对称一步反馈下，已执行身份元数据有方向明确的因果偏好效应”。同时报告事实臂单独的概率变化。

**预定义价值检验**：q12 显示替代臂优于事实臂 **≥1/3** 的样本，使用独立 q3456 对全部五候选算 `V_c = Σ_a p_c(a|s) q3456(s,a)`。报告 `V_FE - V_F0`（相对无标签是否受损）以及 `V_FE - V_FX`（只交换标签时是否受损）。某一比较的 95% CI 上界 < 0，才称该比较检测到判断价值损害。Gold 子集单独复核，报告 n / 轨迹数。

**预定辅助结果**：S 的 `D_id`，F/S 的人工标签切换效应 `D_placebo`、差分 `D_id-D_placebo`、I/U 与 q12 事实动作相对质量分层、argmax 事实动作比例、32B 与可选 7B 的结果。主判断以 32B 为准，不能根据某一个探索性辅助指标更换主结论。

**重要解释限制：** S 的身份信息可能是合理的策略先验；F 的一步反馈并不包含完整未来真值；人造反事实“原动作”标签对事实不真实，因此结果证明的是身份敏感性，不是对真实 L 分布整体偏差的直接因果分解；更不能自动推出学习会受损。

## 必须满足的执行门槛

1. `selftest` 验证编号映射和 F 反馈文本不变；`prepare` 校验 E2 输入 SHA、arms SHA、386 点和全部候选显示顺序，生成请求 SHA/点元数据清单。
2. `score` 必须在单台 GPU、同一模型加载下**同时重做旧 S0/F0 和所有干预条件**；不得将本次 H800 与过去 RTX6000D 评分直接相减。模型 safetensors 与原 P4 E2 固定权重 SHA、原 P4 评分后端 SHA、环境标识和请求 SHA 必须一致；共享前缀/直接评分 TV <0.005 才能写新分数。
3. `analyze` 验证每个请求的哈希及五候选概率完整、模型 run 完成，然后只用独立 q3456/Gold 评价决策价值；以轨迹为统计聚类单位，不把同轨迹的多个点当独立采样单位。
4. 结果写入 `hindsight_judges/results/`，不改原 P4/E4/E4b 的冻结结果、不做新续跑或训练。模型与输入哈希、硬件、耗时及完整自测须随最终报告归档。

本实验没有包含 L 去 CoT / L 截到 t / 双分支完整日志、跨环境或强化学习训练；这些都是之后独立扩展。**即使身份效应为零，A/C 的观察现象仍应报告，改测完整日志的叙事结构而不是否认观察。**
