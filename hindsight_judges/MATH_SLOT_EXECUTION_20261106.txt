Prospective implementation choices for PROTOCOL_NEXT_TOKEN_SLOT_AND_MATH_20261106.md.
No model training or ALFWorld trajectories. Single GPU; start only after both experiment 1 full verifications pass.
Dataset: EleutherAI/hendrycks_math, test, levels 3/4/5, all seven subjects; exact revision and downloaded parquet hashes frozen in prepare.json. Candidate queue is first 512 records sorted by SHA256('20261106:'+subject+':'+original test row index). Never reshuffle to obtain favorable results.
Generate one frozen 7B Student response per candidate. Parseable, non-truncated wrong answers qualify for independent Teacher screening; unparseable or truncated Student responses excluded and reported. Teacher independently generates all four screening answers; require >=3/4 verified correct. Screening uses distinct seeds from every evaluation response. Full evaluation never reuses screening answers as INDEPENDENT outcomes.
All generation uses max_new_tokens=2048, temperature=0.7, full-vocabulary sampling (top_p=1, top_k=0), one sample per evaluation arm, no repetition penalty. Same paired evaluation seed across arms of a question; screening and Student seeds in separate SHA256 namespaces. Pilot/full have different evaluation namespaces. Seeds fixed before outcomes.
Reuse original frozen weights, SDPA MATH, chunk1024; 7B FP32 and 32B FP16 transformer/FP32 head with preserved RoPE buffers. Custom incremental decoding projects FP32 hidden states through FP32 head. Record logits finite checks and cached/direct TV<0.005 before each loaded generation stage, full prompt tokens, generated token IDs, sampled logprob, stop reason, timing and model hashes. EOS tokens come from frozen generation_config.json.
Task instruction: Solve the problem step by step. Give your final answer in \\boxed{...}.
ACTIVE uses original Student prefix in open Assistant. QUOTE-CONTINUE quotes that same prefix in User and asks to continue from interruption, output only continuation, do not restart. QUOTE-REWRITE allows re-analysis and rewritten solution. INDEPENDENT contains only original task. Gold solution is never rendered in any prompt.
Cut proposals: paragraph boundaries before first boxed answer, nearest midpoint of the Student response unless a candidate arithmetic error exists. No eligible paragraph => explicit exclusion. A conservative exact-rational arithmetic checker flags potential false equations for review only; it never automatically declares an error in context. All selected cuts are reviewed before four-arm outcomes. A signed per-question annotation records prefix_end, exact error quotation within prefix and explanation for error_observed; otherwise error_unknown, kept and separately reported. Main correction inference is restricted to error_observed. No automatic claim of correction based on final wrong answer.
Use math-verify==0.9.0, antlr4-python3-runtime==4.13.2, latex2sympy2_extended==1.11.0 in an isolated target directory; freeze full installed package source digest and versions. Require parse fallback_mode=no_fallback, take last parseable boxed answer; other parseable final answers flagged for review. Gold must parse. Evaluation truncation and unparseable output count as incorrect, reported separately. Retention compares final answer to frozen wrong Student answer using same verifier. Manual review of non-boxed answers and deterministic sample 8 per arm (or all if fewer) is required before final verification; retain automated and reviewed labels separately.
Pilot: first 32 eligible qualified questions (or all remaining if fewer). Screening qualification excludes no-paragraph responses before Teacher work. Freeze all pilot cuts before pilot outcomes. Pilot only tests pipeline/timing/cut quality. After verified pilot and review, freeze full budget target up to 200, bounded by the same 512 candidate queue; record expected GPU hours and decision before full outcomes. Full reuses frozen Student/screening/cuts, but uses fresh evaluation seeds in a separate directory. Never select sample size based on arm performance.
Primary: QUOTE-CONTINUE minus ACTIVE final correctness percentage points and retention of wrong Student final answer. Point first, question-cluster paired bootstrap 4000, seed20261106. Report error_observed and error_unknown separately, plus descriptive combined results, screening rates and all exclusions. Secondary lexical correction/restart flags are only heuristics. Four-arm comparison changes task framing as well as role and is not proof of pure role causality or OPD training gain.
Queue pauses at cut/outcome review gates and wakes agent; no user reapproval required. Failures preserve all records and wake agent for repair. No shutdown in this new task.
Use slot_model_loader.py CPU dtype conversion before CUDA transfer for the same documented large GPU cast/fill runtime failure found before experiment 1 scoring. Numerical policy and checkpoint values unchanged. No GPU fill/cast workaround changes model scoring or sampling settings.
