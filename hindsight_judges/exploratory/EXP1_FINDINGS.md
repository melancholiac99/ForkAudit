# 实验一：结果解读与事后分析（2026-11-03）

**性质：** 第 1 节复述预注册结果（已用原始分数独立复核，与 `results/exp1_p4/*/REPORT.txt` 一致）。第 2–4 节是**事后探索性分析**，没有预注册，只作解释和下一步实验的依据。数字由 `exploratory/exp1_posthoc.py` 生成，完整输出见 `exploratory/exp1_posthoc_out.txt`。CI 均为按轨迹聚类的 bootstrap 95% 区间。记号：f 为执行动作，b 为 q12 最优替代；标签 E 表示"已执行 = f"，X 表示"已执行 = b"，PE/PX 表示把"任意标记"放在 f/b 上。

## 1. 预注册结果（协议 v2）

| | 32B（主模型） | 7B（辅助，FP32） |
|---|---|---|
| F 身份切换，对数几率 | **+0.92 [0.79, 1.07] nat** | +0.30 [0.23, 0.37] |
| F 身份切换，概率 | **+3.47 [2.16, 4.87] pp** | +1.17 [0.51, 1.86] |
| F 价值，事实动作差 ≥ 1/3：V(E) − V(0) | **−3.44 [−5.85, −1.29] pp** | 未检出 |
| 同上：V(E) − V(X) | **−1.76 [−2.72, −0.88] pp** | 未检出 |
| Gold 复核（≥ 1/3） | −3.63 / −1.15，CI 均不含 0 | — |
| 预定义辅助：身份 − 任意标记（F） | **−1.64 [−1.82, −1.46] nat** | −2.50 |

按协议，32B 的四项预定判断全部成立：在 F 的对称一步反馈下，"已执行"标签对评委偏好有因果影响，并造成判断价值损失。S 下同样成立，且效应更大（身份 +1.45 nat）。

**但预定义辅助比较方向相反：** 一个明说"任意、不含质量信息"的标记，效应是"已执行"标签的 2.8–5 倍（32B：S +5.04 对 +1.45 nat，F +2.57 对 +0.92 nat）。所以本实验证明的是**评委对"指向某个候选的元数据"敏感**，而"已执行"这一语义不是必要条件。

## 2. 标签效应的形态（事后分析）

1. **它是加在被指候选上的对数几率偏置，与指向哪个候选无关。** `sequence_logp` 的上限是 0：F 下 b 有 53% 的点已经在天花板上，导致原始分解看起来不对称（X 推不动 b）。只在被指候选还有提升空间（无标签时 log-prob < −1）的点上计算，32B F 下 E→f +1.27、X→b +1.06、PE→f +3.00、PX→b +2.78 nat，S 下分别为 +1.77、+1.80、+5.39、+5.62。按显示位置看，32B 的效应准确落在第 N 位；7B 有一部分溢出到第 N+1 位（SE：N +0.01、N+1 +0.52），7B 的身份估计偏低，只能参考。
2. **与动作价值无关。** 32B F 下身份切换对 q3456(f) − q3456(b) 的斜率为 −0.02 [−0.33, +0.23]，任意标记 +0.03。
3. **与可见证据无关。** 在 F 已经显示"f 没找到目标、b 找到了"的 211 个点上，32B 身份切换仍为 +0.93 nat，和其他点（+0.82、+1.03）相同。偏置是叠加在证据之上的。
4. **决策后果取决于证据强弱。** 证据强时（F），偏置很少改变选择（上面那 211 个点上，argmax = f 的比例从 8% 升到 10%，任意标记 15%）；证据弱时（S）改变得多。指针指向好动作有益（32B 任意标记放在 b 上：S +6.79 pp，F +1.63 pp），指向坏动作有害。事后日志里的指针永远指向已执行动作。
5. **提示层面的去偏无效。** 所有条件的基础 prompt 都含 "Do not copy an action merely because it appears in a recorded future"；任意标记还明说 "carries no information about action quality"，却仍是最强的。"已执行"标签使评委放弃本已选定的候选（p > 0.9 降到 < 0.5）的情况很少：32B F 下 5/264，任意标记 0/264。这是 F 下 X 标签小幅损失价值（−1.47 pp）的来源，不成系统。

## 3. 与"为已发生的选择辩护"的关系

结果不支持"动机性辩护"式的解释：起作用不需要"已执行"的语义；7B 评委就是策略本身的 checkpoint，对"原 agent 执行了第 N 个"的敏感度却不比 32B 高。注意这不是自我归因检验：标签说的是 "the original agent"，不是"你"；7B 还有数位置误差和精度差异。更简洁的解释是**指针/显著性**：上下文单独点出哪个候选，评委就给它加一个与证据无关的先验。这与 suggested-answer / hint 类偏差一致。

## 4. 与原 L 锚定的量级对比（跨运行，只看量级）

同 386 个 Fork、同一种 f:b 对数几率口径，原 P4 E2/E2-M 的 32B：L − M **+5.36 [4.43, 6.43] nat**，L − S +3.90。本实验 S 下：任意标记相对无标签 +4.77，"已执行"标签 +1.34。一句任意标记引起的偏移与完整日志同一量级；单句"已执行"标签约为其 1/4。

原 L 的偏移里另有一部分随动作价值变化：执行动作相对替代均值的 L − M 偏移，均值 +5.34、标准差 5.13，对独立回放优势的斜率 **+2.73 [+0.40, +5.20] nat/单位**。这是事后信息的有用部分；常数部分（约 5 nat）大小与指针效应相当。74% 的方差在轨迹内，所以 HCAPO 式的轨迹内自归一化只能去掉每条轨迹的均值，去不掉这部分。

## 5. 对故事和下一步的含义

- **主线修正：** 事后信息 = 指针 + 信息。指针给被指候选加一个与证据无关的常数偏置；事后日志的指针总是落在已执行动作上，所以证据越弱的分叉，评委越难纠正原策略。去偏应当去掉指针（对称呈现分支、不说明哪一支是真实执行的），而不是靠提示词。"Defend what was done" 这个标题建议换掉。
- **实验 1c（只需打分）：** 在真实 L 格式上拆解指针：L、L 去 CoT、L 截到第 t 步、对称双分支（执行分支和 b 分支匿名为 A/B、顺序随机）、M，全部在同一次运行重新打分。主问题：对称双分支能否保留随价值变化的部分（斜率），同时去掉常数偏置。双分支需要用 ALFWorld 确定性重放重建 b 分支的观察文本（CPU）。
- **可选小补：** 去掉反照抄句后的 E/X/PE/PX，以及只写 "Note: candidate number N." 的裸指针，用来解释为什么任意标记比"已执行"更强。这不是故事必需的。
- **实验 2：** 按偏置能否进入训练来选目标函数：比较式（评委 argmax 对执行动作）和蒸馏式会受影响；轨迹内归一化的比值式只能部分抵消。
