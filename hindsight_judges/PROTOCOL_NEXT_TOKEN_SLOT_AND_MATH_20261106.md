## 一、背景与要检验的问题

在已有 P4 386 点/60 轨迹上，32B Teacher 在五臂对称特权证据 F 下：当前 Assistant 前缀 KEEP 的离线五候选价值约 42.2%，User 引用 QS 约 52.7%，QO 约 61.0%，完全移除 Think 为 67.8%。去均值证据斜率比（相对 DROP）约为 KEEP 0.55、AP 0.86、QS/QO 1.10。7B 在保留 Student 理由时几乎无法改善动作价值；M 条件下 P4 Teacher 本身几乎没有可测的任务价值排序能力。

现有动作层面对比外推的复算表明，四分布差分目标 **尚未稳定胜过** 单槽位对比放大。后续不能只和标准 OPD 比；**单槽位放大 T1 是最重要的强基线**。

两个可证伪问题：

1. **方法可行性：** 槽位带来的 F−M 额外证据信号能否在 **Student 已生成前缀 y_<t** 的各 token 位置转化为稳定、可对齐、优于 T1 的 OPD 目标，而非只改善最后动作重打分？
2. **一般性：** 在没有 F/参考答案的数学任务中，Teacher 本身具备独立解题能力时，改变 Student 错误前缀的呈现方式能否提高自然续写后的恢复率？

这两个实验互不以对方结果为先决条件，可并行推理；不宣称已证明训练收益。

# 实验 1：P4 逐 Token 槽位诊断（32B 为主，7B 对照）

## 1.1 样本与复用

- 复用 **全部 386 个冻结 P4 点**的原 Student（7B、M）实际写出的 Think+Action、相同 M/F、五个合法动作、冻结 q3456、原轨迹 ID。
- 沿用已有 action_diagnostic 的动作/格式解析与独立 q3456，token_diagnostic 的 canonical response 重编码及全词表评分后端，prefix_attribution_v2 的真 chat template 和外部引用构造。核对 token round-trip、模型与原始文件哈希。
- 同一位置 t **只能看到 y_<t，不可预先引用完整 Think 或实际后续动作**；F 可以是所有候选对称的一步证据，但绝不可泄露该响应的真实未来。Student 参考始终为 7B 在 M 下同一 token 前缀的分布。
- 一张 GPU 按阶段顺序加载 7B（计算承诺曲线和必要 Student 参考）及 32B（主诊断），无需同时驻留两个模型。另一张 GPU 可跑数学实验。先用 **32 个点**试跑核对时长、显存、token 对齐和数值门槛，正式预算以实测为准。

## 1.2 首先定义承诺点 k，不根据最终效果倒推

用原始 Student 的 Think，沿**真实文本的句末/换行边界**截取逐渐增长的合法前缀 h；每个边界临时闭合未完成 Think 并补动作开标签，然后在 **7B + M** 下给五个固定动作字符串打分，得到 p_7B(f|h,M)。

- **k 定义：** 首次达到 p(f) ≥ 0.90，且在余下所有被检查的边界不再低于 0.90 的边界。记录每条轨迹的完整 p(f) 曲线。
- 若不存在这样的 k，标为 **no-k**，仍报告/保留样本在整体分析中；**不得强行指定 k**，不得把 no-k 样本混作“承诺之前/之后”。
- 所有边界在看到新 Teacher 分数前固定；动作开标签格式、预期候选序列与原先评分一致。必要时报告“最早达到 0.9 但后来跌破”的暂时承诺，作为描述而不是替换定义。
- 在同一 h 上给 **32B 两槽位 × M/F** 做动作探针，绘制动作钉住曲线及独立 Q 加权的价值曲线。

**重要区分：** 人为补闭合 Think + 动作开标签，是一个 **counterfactual action probe**，用于估计这段推理到目前为止把模型钉向哪个动作；它 **不是真实位置 t 的下一个 token，也不能直接当作 OPD 梯度**。真实逐 token 诊断必须保留原响应在 t 处的自然生成边界（见下节）。

## 1.3 两套互补的评分位置：不要混淆

**A. 原生逐 token 位置（主方法可行性分析）。** 在固定的学生回复 token 流中，以未见新实验分数前确定的规则选取：
- 普通 token 边界：k 前、k 后的完整单词/句子边界，各抽相近数量（例如各 2–4 个）；原始 Think 的第一段和最后一段也覆盖；
- 在学生推理**第一次明确提到实际候选目标/动作**附近的词边界（仅当原文可以无歧义定位时）；不能识别的点标注并保留其他位置；
- 原始 Action 内容的首 token / 首个可区分 token，独立于 Think 位置报告；
- k 不存在时单列 no-k，避免提前/之后组被选择性污染。

对每个原生位置 t，预测的都是**原文真正的下一个 token y_t**，不插入闭合标签、不在普通句子里直接强行评分完整动作字符串。可记录 Student 下一 token 的 logprob、Teacher 全词表分布、KL、重启/复述倾向，以及对应的 token-level 代理信号。

**B. 动作探针位置（辅助、连接已有 q3456）。** 在相同的固定句子边界 h，**另起一条仅用于诊断的分支**：按统一格式闭合 Think/打开动作标签，再对五条完整动作序列求条件 logprob、五候选 softmax 概率、独立 Q 加权价值、M→F 价值对齐斜率。要比较 T0/T1/T2 的动作探针价值，须按候选动作多 token **逐个计算整个动作序列的目标分布概率**（或明确只比较同一可区分 token），不得把一个 token 的概率当作整段动作串概率。探针价值是训练相关性的间接证据，**不是完整 OPD 学习收益**。

两个数据切片使用同一个样本 ID、h/k、原始词边界和独立 Q；各自标注 probe/native，结果不能合并成一个 OPD 指标。

## 1.4 四个 Teacher 分布（同位置、同 Student 已生成前缀）

定义模型对同一词表中 token v 的分布：

- p_AF(v|h)：标准 **当前 Assistant 续写**，有 F；
- p_AM(v|h)：同一标准槽位，无 F；
- p_EF(v|h)：将 h **逐字作为 User 引用**，另开 Assistant，固定提示“从中断处接着写，只输出续写”，有 F；
- p_EM(v|h)：相同外部形式，无 F。

标准与外部分布的 **预测 token ID/词表完全相同**；必须用真实 chat template，保存完整结构化消息、渲染 token、指令、action probe/native 类型。外部条件只给 h，不给 y_t 或任何后续，保证无未来泄漏。

**特别注意**：在“句中 y_t”位置，外部 Teacher 可能想重写/重新开头。这不妨碍用它作校正信号，但会影响纯外部 p_EF 是否能直接用作监督目标；报告而不替换其分布。

## 1.5 预定义目标 T0–T3

所有 logprob 以 **FP32 full-vocabulary log_softmax** 计算，构造后重新归一化；主参数 **β=1**，β=0.5 和 2 只做敏感性分析。

- **T0：标准 OPD Teacher**  
  log T0(v) ∝ log p_AF(v)
- **T1：单槽位 F−M 对比放大（强基线）**  
  log T1(v) ∝ log p_AF(v) + β[log p_AF(v) − log p_AM(v)]
- **T2：四分布槽位差分（候选方法）**  
  d(v) = [log p_EF(v) − log p_EM(v)] − [log p_AF(v) − log p_AM(v)]  
  log T2(v) ∝ log p_AF(v) + β·d(v)
- **T3：纯外部分布（参考，不默认直接训练）**  
  T3(v) = p_EF(v)

T1 在所有对照中保持**同一定义、同一 β 参数与归一化语义**。不能把上一次动作级实验的 β 数字不加核对地移植为完全同一参数含义。

T2 同时报告：
1. **截断版**：d 在 [−5, +5] nat 截断；
2. **未截断版**：报告极值、溢出风险、分布漂移，数值异常须显式标记；
3. **全词表版**；
4. **top-K 并集版**（固定 K=128，可另做 K=64 敏感性）：只在 union(topK(p_AF), topK(p_EF)) 内施加 d，**集合外保留 p_AF 的原始 logits/概率，再对全词表归一化**。

**不可将 top-K 集合之外的 token 概率直接设为零**；那样面向全词表的 OPD KL，尤其 KL(Student||Teacher)，可能变成无穷大。top-K 是“允许调整的支持集”，不是把其余词从可预测词表删除。完整分布下的数值计算保持 finite 检查。

如果 T2 与 T1 比较差，只看一个 β 或选择最有利的截断方式不能构成正面结论。主比较固定为 **β=1、T2 截断±5、全词表**；其他配置作为稳定性分析。

## 1.6 报告指标与先写好的判停规则

**动作探针（按 k 前/后分别报告，汇总以轨迹聚类 bootstrap）：**
- T0/T1/T2/T3 对完整五个候选动作的归一化概率、q3456 加权价值，**T2−T1** 的配对差及 95% CI；
- 四个原始 Teacher 分布中 F−M 造成的动作相对 log-odds 增量，以及对独立 Q 的斜率；
- 每个边界的 p(f)、是否达到稳定 k、k 前/后的曲线与 no-k 比例。

**原生逐 token（按 k 前/后/普通位置分别报告）：**
- KL(T_i || p_AF) 与 KL(p_AF || T_i)（写明方向）；Student 实际 y_t 的 logprob 改变量；
- T_i 分配给重新开始、复述、格式转换类 token 的概率质量及首 token 排名变化（重启集合需事前按 tokenizer 固定，并承认多 token 重启不能被单词表完全捕获）；
- sampled-token proxy log T_i(y_t) − log p_student(y_t)，与最终事实动作 q3456(f) 相对替代动作 Q 差距的相关性/回归斜率；**这是代理量，不是已测 OPD 梯度或训练收益**。
- 动作内容、Think 内容、格式 token 分开；普通位置还应统计 T2 对合理自然续写是否破坏，不能仅报告动作探针利好。

**工程判停规则（探索性、不是统计显著性的普遍标准）：**
- **进入训练设计候选：** 在**k 前**有足够样本的动作探针上，预先固定的主 T2 相比 T1 达到 **≥3 pp 且轨迹 bootstrap 95% CI 下界 >0**；并且普通原生 token 上 T2 的 KL 漂移不比 T1 更严重，Student 下一个真实 token 的平均 logprob 相对 T1 不明显下降（预先记录具体容忍阈值，例如 0.1 nat/token，连同其 CI）。这是**值得进入训练的最低门槛，不是证明可训练**。
- **T2≈T1 或弱于 T1：** 不主张新的槽位差分算法优越；将槽位结果定位为机制解释或同现有对比外推的补充。
- **改善只在 k 后：** 只主张可能的**错误后修复**价值，不能称为提前防错。
- **若大部分样本无 k、k 前几乎没有可测试位置：** 先完整报告可用样本和有效性，再决定训练；不能换定义寻找正结果。
- **T3 自然续写保真度差** 不自动否决 T2；真正看要使用的目标 T2 是否保留有效的 token 续写和 Q 对齐信号。

**统计：** 386 点，原 60 条轨迹为 cluster，4,000 次配对 bootstrap，seed 20261106；报告样本数及有效 pre-k 占比，避免同一轨迹多个 token 当作独立样本。试跑的前 32 点只验程序和测速，不做论文显著性结论。

# 实验 2：不带特权信息的数学前缀槽位测试

## 2.1 目的与样本

对照实验 1 只显示特权 F 下效应的限制，在**Teacher 仅靠原题和自身知识**时检验：外部化错误前缀是否使其更能纠错。

- 学生 Qwen2.5-7B-Instruct；Teacher Qwen2.5-32B-Instruct；**MATH level 3–5**，冻结可追溯的 dataset/revision/split、题目 ID 和顺序，使用参考答案仅作**离线筛选和评分**，绝不进入 Teacher 的输入。
- 先生成 Student 答案并核实**最终答案错误**；Teacher 从头独立作答 4 次，筛选 **至少 3/4 正确** 的题。筛选 seed 与后续四条件测试 seed 分开；独立作答基线仍须在评测阶段**重新采样**，不要把筛选的 3/4 当作评测正确率。
- 从 Student 原文的**段落边界**构造截断前缀。**关键检查：最终答案错误不等于截断前缀已经包含错误。** 要称为“错误前缀的恢复”，至少为主队列标出一个**已经写下错误推导**的边界（可用可验证算式/人工抽检；难以判断的单列“错误位置未知”，不混称 correction）。可保留错误发生之前的截断作辅助。
- 固定一个可负担的候选队列，先 **32 道符合条件的题**试跑，测速和审阅截断质量后再定全量规模（例如 200 道合格题）；不足时报告筛选率，不得改变标准追求正结果。

## 2.2 四种条件（同题、同截断 Student 前缀）

1. **ACTIVE**：Student 原样文本位于当前 Assistant 生成前缀，Teacher 从断点自然续写；
2. **QUOTE-CONTINUE**：相同已生成前缀在 User 中作为外部草稿引用，要求从断点接着写，不能主动重做；
3. **QUOTE-REWRITE**：相同外部引用，允许重新分析并重写解题过程；
4. **INDEPENDENT**：不给 Student 前缀，Teacher 从头独立解题。

所有条件不给标准答案、参考推导、F 或额外 critique。保持任务说明、模型、生成预算、温度与采样 seed 设置一致，并为不同解题形式提供**相同最大生成 token 预算**。同题多条件配对评估，明确从中间前缀继续写的剩余上下文与重写流程不可强行要求相同推理长度。

**注意结论范围：** (2)−(1) 同时改变槽位与新一轮生成/要求续写的任务形式，所以能证明“外部化呈现干预在无 F 下是否有用”，**不能单凭这一项严格证明只由 role token 触发**。如果出现强效应，可后续补原 P4 的 AP 型“历史 Assistant 已完成 + User 同一句请求”来拆开槽位/重启，不作为本次四条件必须增加的第五臂。

## 2.3 指标、判读和可靠性

- 主要：每题 Teacher **最终答案的正确率**（自动 verifier + 抽样人工核查不可靠格式），**相同错误学生前缀被沿用到最终答案的比例**；报告错误已发生/错误位置未知两种队列的数量与正确率，主推论限已标注错误的前缀。
- 次要：下一段是否出现明示转折/修正、是否重新开始推导、是否违反“从断点续写”的请求；转折词概率不可替代正确率。
- 优先比较 **QUOTE-CONTINUE − ACTIVE**；允许重写和独立作答只是重要参照，二者优于 ACTIVE 不足以证明同前缀修复能力。
- 固定题目 ID、学生回复、截断、四条件 Teacher 响应 seed；按**题目**成组 bootstrap（若一题多个截断，应在题级聚合），报告 95% CI、绝对值、条件正确率与筛选率。
- **解释：** 引用续写明显优于当前 Assistant 自然续写 → 无特权信息也能从这种干预获益，支持从 agent 特权反馈到一般推理任务的推广；二者接近 → 该方法在当前数学设置中未显示一般性，结论暂收窄到特权 F 下证据吸收；任何情况都不直接等同于 OPD 训练收益。
- CriticOPD 中报告的独立与带错前缀正确率仅为研究动机；**不要预期或引用 0.82→0.29 作为本次 Qwen/MATH 配置的实测基线**。

# 四、阅读结果时最重要的三个判断

1. **逐 token 方法是否真的胜过 T1**，而不是只胜过标准 OPD 或在动作探针上择优调 β；
2. **承诺前是否出现有效监督**，以及是否同时保住原生续写格式；动作探针好并不能自动证明逐 token KL 好；
3. **无特权数学题能否从同一个真实错误前缀恢复**；只证明外部允许重写正确率高，不足以支持一般化纠错机制。

**预期研究结论允许是负面的。** 若 T2 不胜 T1，仍可保留消息槽位对特权证据使用的机制结果；若数学无效果，收窄结论。不能把单次诊断的离线分数称为已经证明的 Student 学习收益。
