# 事后探索：分层、预算强制和次选放大

沿用同一 MATH-500 非思考 16k 配置及同一固定探针。准确率为逐题平均两条回答的正确性。所有区间整题 bootstrap 10,000 次，种子 20261124。

分层分别采用 B 两次采样平均正确率及数据集 level。各层按一次采样的 R 减 B 长度差排序，用另一次采样计分，两向取平均。奇数层中位题各占两组半权，长度相同时按题文本排序。层内重抽并重新划分，合计按原题数加权。B 正确率层使用了计分时同两条 B 回答，存在数学耦合。

强制对象 B 和 R-cond@100，每题、每采样编号使用原 R@100 的实际长度 L。首段沿用原评测器的提示、vLLM 配置和 seed 1001、n=2；后续从原 token 历史续写，使用由 1001、原采样编号与续写轮次确定的新随机流。每次提前 EOS 去掉 EOS，加入完整的换行两次和 Wait,，最多 8 次。达到 L 后正常生成，16,384 为总上限，注入 token 计入预算；空间不够完整注入时保留原停止。按最后 boxed 判分。用数据集顺序均匀选 20 题，在两个模型各完成 40 条，报告四卡实测总耗时，再补齐其余 480 题，复用试跑。完整回答和 token 序列存保留盘。

次选预测在看本项读数前记录。温度 1.1、全词表、固定原老师及初始 B。采用严格大于 0.05 的有符号元素 KL 截断判定，U 为其补集，q(U) 为老师质量。预期仅在老师首选被截位置，R 的首选等于老师第 2 名的频率、对第 2–5 名的概率比、单 token 反思词概率高于 B 和两个新组；R 的概率比大于 1 并随 1/q(U) 增大；两个新组的概率比不超过 1。b 先在每位置等权平均四个 log 概率比，再对位置平均并取指数。五档按所有首选被截位置的 1/q(U) 等频分组，bootstrap 固定这些描述性分界，报告 R 与 B 的比值、算术差及配对区间。反思词报告每个单 token 拼写和去重总质量，包含有/无前导空格形式。按问题配对重抽，以位置累计量计算位置加权均值。
