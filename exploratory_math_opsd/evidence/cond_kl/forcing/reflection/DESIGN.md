# 反思词针对性与 Wait 分叉（事后探索，已见前序结果）

固定 B 的 1,500 条回答、原提示和分词。参考答案优先使用训练数据独立 Answer 字段，缺失时使用参考解答末个 boxed，仍缺失则排除；生成回答用官方末个 boxed 提取及判分。主分析包含缺少 boxed 的回答（计错）；另报正常 EOS 且有 boxed 答案的敏感性结果。最终判错描述 B 的整条回答，不给中间步骤贴错误标签。

边界只看已生成前缀。句末是新 token 以英文或中文句号、问号、感叹号收束（可含闭引号和本 token 的尾部空白）；段末是首次形成空白行。数字后孤立的小数点保守排除，不用将来 token 识别小数。两个条件重合时算段末。只纳入存档中确有下一个 token 的位置，另列句末和段末。温度 1.1，全词表归一，词集 Wait、But、Hmm、Alternatively 各自有/无前导空格的单 token 形式。用逐位置概率和衡量这四个词启动下一个 token 的概率。对 B、T0、R、R-noclip、R-cond、P（训练组均 @100），报告错/对两组均值及其自然对数比，以相对 B 的错/对对数比差衡量“增幅是否更有针对性”。报告在正确和错误组分别相对 B 的变化。整题配对 bootstrap 10000 次，种子 20261124。预期 R 在判错回答上增幅更大，T0 的相对增幅与对错无关，两个取消截断组增幅小；不设事后等效阈值。

反事实聚焦 R@100，同一 B 句末前缀，四对续写。每题至多均匀抽两个句末，再从池中均匀抽至多 2048 个，选择只用位置与题号、种子 20261124。第一步温度 1.1，强制 Wait 时在有/无前导空格两种 Wait token 中按 R 原概率选；对照从全词表去掉这两种后按 R 的条件分布选（允许 EOS 和其他反思词）。随后按探针原采样设置 1.1、top-20、top-p .95 续写，臂间共用后续种子。总回答上限沿用 1024，剩余长度含干预 token，报告触及上限比例。拼回相同前缀、按最终 boxed 计分。先测 32 个位置，再补齐，复用试跑。报告强制 Wait 减对照的剩余长度和正确率，按题整簇重抽。进一步比较按 R 自然 Wait 概率加权、按 B 自然 Wait 概率加权和各位置等权的正确率效应；在同题两分叉中比较 R 更倾向 Wait 和较少倾向 Wait 位置的效应。这些量用于区分“Wait 平均有用”和“R 更倾向在有用处 Wait”。单次干预只识别该策略、前缀与预算下的局部效应。
