# MATH-500 非思考预算强制第二轮（事后探索，已见八次追加结果）

B、T0@100 各 500 题，每题两条。每条沿用同一题同一采样序号的 R@100 原始 token 数 L。原四个 TP=1 引擎、20 题试跑后复用、种子 1001、非思考模式、温度 0.7、top-p 0.8、top-k 20、min-p 0、16,384 token 上限和官方末个 boxed 判分不变。追加文本为两个换行加上 “Wait, let me re-examine this from the beginning.”，每条最多追加 32 次。

按模型报告正确率、实际长度减 L、Pearson 相关、0 至 32 次追加的计数和占比、达到 0.9L 的回答比例。四个准确率差为 B 强制减 B、B 强制减 R、T0 强制减 R、T0 强制减 T0。每题两条得分先平均，按题配对重抽 10,000 次，种子 20261124，取 95% 百分位区间。敏感性主表按强制模型分别选两条都达到 0.9L 的题；另报逐回答筛选版本，仅保留达标采样并使用相同题和采样序号的基线，仍按题重抽。两种子集均按干预后实现的长度选择，有选择偏差。

在完整试跑结果产生前补充共同子集：四项比较也在 B、T0 各自两条采样全部达标的同一组题上并列报告。

## 追加登记（全量 B 刚开始；未查看正确率、长度或其他结果）
按强制模型分别判定：平均长度 ≥ 0.9 × 平均 L，且至少 80% 的回答长达 0.9L，为匹配合格；不合格只作部分证据。合格且强制减 R 的配对区间含 0、强制减原模型的区间下界 > 0，按登记解释为收益主要来自推理时间；合格且强制减 R 的区间上界 < 0，按登记解释为该干预提供的推理时间解释不了全部收益，支持组织方式解释；其余无定论。区间含 0 不是等效检验。另列达到 16384 的比例，每次追加带来的平均 token 数（有追加的回答合计净增长除以合计追加次数，另报逐回答比值平均）。
首次追加前逐 token 对照同题同序号的原回答，追加处应是原 EOS；无追加的比整条。若只有解码文本则独立标注可验证范围，不把重分词当成原始 ID。另报对→错、错→对条数，占全部及原状态的比例和按题配对重抽区间，以及 R 对原 B 错的回答中 B 强制后改对率、平均长度减 L 和达标率。配对转移照实给出，解释需区分前缀能否核实。达标子集为次要结果。

### 解读补充（全量 B 尚在生成，未读取本轮准确率）
EOS 追加预期发生在首个可判分答案之后，且追加之前与原回答相同。两项均按回答核对；报告 explicit 和 boxed 下强制与原回答的首答案正确率、配对差及是否在首次追加时已给出首答案。未检出、前缀不同、首答案改变均单列。原回答只存解码文本，原始 token ID 同一性不可直接验证。核对成立时，最终正确率的变化只来自改对和改错。合格但 B-强制32 显著低于 R 时，结论限定为“首答案之后加长不能替代 R 的收益”；T0 同理。不推广到首答案前延长推理的效果。长度不合格时仍只作部分证据。
