# R-contrast-v2 修复诊断

在前 25 步存档中，26 道题同时具有自然结束的训练回答、原负例和 B 的已判对完整框答。四种配置复用其 17,685 个回答 token，包括 26 个实际结束 token。下表为实际采样 token 在正、负老师下的半对数概率差（自然对数，温度 1.1）。结束符为按题重抽的 95% 区间。其余各项完整区间和各自分母见 diagnostic.json。

| 正上下文 | 填充 | EOS 均值 [95% 区间] | Final Answer | boxed 标记 | 全部位置 |
|---|---|---:|---:|---:|---:|
| 参考解 | 原右填充 | −0.279 [−0.721, 0.082] | −0.109 | −0.011 | 0.007 |
| 参考解 | 左填充、紧凑编号 | −0.614 [−1.172, −0.225] | −0.110 | −0.005 | 0.006 |
| B 判对回答 | 原右填充 | 0.092 [−0.114, 0.338] | −0.132 | 0.011 | 0.001 |
| B 判对回答 | 左填充、紧凑编号 | 0.055 [−0.038, 0.168] | −0.146 | 0.010 | −0.001 |

默认配置的区间上界为 0.168，保留全词表对比。换用 B 的判对回答与 EOS 信号变化一致，同样的变化没有出现在 Final Answer 上。抽样限定于早期能自然收尾且两种上下文齐全的题。B 回答自身也单列评分，见 JSON 中 B/ 行。原 B 采样只存了解码文本，未保存终止 token ID 或 finish_reason，其 EOS 栏记为缺失。用于正、负上下文的 B 回答也可能是该列的被评分回答。

原右填充分支按训练时四条一组的宽度重建，替换 B 正例时仅对缺失正例的同批陪衬题回退到参考解。训练回答从存档文本重建 token。使用原训练模型、BF16、FlashAttention 2 和 FP32 对数概率。padding_test.json 另报告用真实基座在 FP32 下逐项比较单条和混合长度批次回答 logits 的最大误差。
