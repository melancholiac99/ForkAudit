# 长推理的组织（事后探索，已见前序结果；只用 CPU）

比较 B 和 R@100 的归档自然回答。MATH-500 非思考与思考分列；思考模式的 AIME24、AIME25、HMMT25 按基准分列并等权合并。按原题文本和采样序号对齐。所有不确定性用题级配对 bootstrap（10,000 次，种子 20261124）；比赛合并在各基准内重抽。无新生成。

反思持续性：以独立英文词 Wait（忽略大小写）为事件。报告连续两个 Wait 间距不超过 64 个重分词 token 的比例。在每条回答内保持长度和 Wait 数，从 token 位置无放回均匀抽取相同数量的事件，作 128 次打乱，报告实际值、对照和差。成串比例的分母是同回答相邻 Wait 对的数量。验证转移以空行分段，段首 18 个英文词内含 double-check、check、verify、verification、recheck 或 verifying 算显式验证段。看下一非空段是否仍为验证或以 Wait/Hmm/But/Alternatively 开头，报告继续反思、转入其他段、结束三类比例。这是带词标记的代理，其他段含隐式验证的可能性存在。

定论时机：仅分析思考模式，以首个完整 boxed 或明确归于答案的陈述（the/my/our/final answer is、should be、would be、must be、冒号或等号，后接可完整解析的数学定界表达式或独立数值）中较早者为首个可判分答案，另做只认 boxed 的保守口径。首答案的结束处为切点，前段含该次提出答案的文字；未检出者整条计入“尚未检出答案”时长，后段为零。报告全体和同题同采样两模型均检出子集，覆盖率分列。文本用原 tokenizer 重新分词，另报归档原生总长度。首答案用官方判分，末次用存档判分。先错后对同时按全部回答和首答案错的回答为分母，也报先对后错。自动抽取看不见未明说的候选答案；不把时间先后解释成收益来源。
