# E4 预注册：反馈锚定的步级信用能否改进学习（闭环实验）

- **日期：** 2026-10-31。**状态：** 预注册；运行前单独提交（提交信息 `E4: pre-registration`），hash 写入 DECISIONS。
- **依据：** `proposals/P5_closed_loop.md` §3.3 与 §10.3；P4 E2 / E2-M 的预注册结果。
- **代码：** `exploratory_E4/`，所有判定规则集中在 `e4_common.py`，`test_e4.py` 在 CPU 上全部通过。其中一项测试用 P4 E2 的真实请求，验证 E4 生成的评判上下文与 P4 E2 逐字节一致。
- **已看过：** M0、P4（E1、E2、E2-M、P4-X）的全部结果。**未看过：** 任何 E4 数据（ALFWorld 训练游戏上的轨迹、标签、训练与评估结果）。

## 1. 问题

在不做完整回放的前提下，用"执行候选动作一步、按动作记录反馈，再由评判者选出更好的动作"得到的步级偏好训练策略，能否在同等成本下：
- 优于不训练；
- 不劣于、甚至优于回放信用；
- 优于事后日志评判者给出的信用；
- 且收益不只是因为"多探索"或"随便换一个动作"？

## 2. 数据

- **游戏（`e4_00_freeze.py` → `games.json`，先单独提交）：**
  - train：从 ALFWorld train 中排除 M0 的 100 个任务后，按六类任务分层抽 400 个，种子 20261031；
  - tune：再抽 40 个，只用于选学习率；
  - 评估：valid_seen 与 valid_unseen 的全部游戏。
- **训练轨迹（`e4_01_rollout.py --split train --full`）：** 每个训练游戏一条。基座策略、模板、两轮历史、温度 0.7、50 步上限、解析器均与 M0 相同。
- **决策点（`e4_02_points.py`）：** 训练轨迹中每个"搜索阶段"的步，定义为决策时 prompt 中没有任务目标物体的实例（与 P4 的 `prompt_target = False` 相同）。
  - 替代动作按 M0 协议生成：32 份草稿一批，最多 300 份，取前四个不同的合法动作；不足四个的点不标注。
  - 五个臂各执行一步，记录环境返回；实际动作那一臂的返回必须与原轨迹一致。

## 3. 各臂（每臂产出"同一 prompt 下偏好回复 ≻ 不偏好回复"的偏好对）

臂 0 是实际执行的动作。替代臂的回复文本取草稿中第一份解析为该动作的完整回复（含思考）。

| 臂 | 选点 | 偏好规则（`e4_common.py`） |
|---|---|---|
| **A**（主方法） | 全部决策点 | 32B 评判者在 P4 E2 的 F 条件下（决策上下文 + 五臂带对应一步反馈）的 argmax；不等于实际动作时，argmax 臂 ≻ 实际动作 |
| **A′** | 同上 | 规则：实际动作的一步返回不含目标实例、而某替代含有时，第一个含目标的替代 ≻ 实际动作 |
| **H**（事后评判） | 同上 | 32B 评判者在 L 条件下（决策上下文 + 完整事实轨迹与结局）的 argmax ≻ 实际动作 |
| **Rnd** | 与 A 完全相同的点 | 均匀随机一个替代 ≻ 实际动作（检验 A 的"选哪个"是否有信息） |
| **D**（探索启发式） | 全部决策点 | 实际动作不是"去新地方 / 开新容器"（`arm_classes` 的 E_new）、而某替代是时，随机一个 E_new 替代 ≻ 实际动作 |
| **Bfull** | 全部决策点 | 每臂续跑 3 次（共 15 次）得估计值；最高 ≻ 最低，差距 ≥ 1/3 才成对 |
| **Bmatch** | 与 A 同等标注成本的均匀随机子集 | 同 Bfull |
| **Cmatch** | 同等成本、采样熵最高的点（CARL 式） | 同 Bfull |
| **Esft** | 训练集中成功轨迹的步 | 只用结局的拒绝采样微调（SFT），样本数与 A 相同 |
| **base** | — | 不训练 |

## 4. 成本与样本量

- **标注成本按同一块 GPU 的实测秒数计：**
  - A 的成本 = 32B 评判 F 条件的打分秒数（不含模型加载）；
  - 回放成本 = 全部回放的墙钟秒数 / 回放点数；
  - Bmatch / Cmatch 的点数 N_match = ⌊A 的成本 / 每点回放成本⌋（`matched_count`）；
  - 草稿与一步执行为各臂共用，不计入；一步执行在 CPU 上，单独报告。
- **训练样本上限：** 每臂最多 1,000 个样本（带种子的子抽样，`cap_rows`）。Rnd 与截断后的 A 保持完全相同的点；Esft 样本数等于截断后的 A。截断前的计数一并报告。
- **对比的含义：**
  - A 对 Bmatch：同等成本；
  - A 对 Bfull：在上限内同等样本量，比的是标签质量（Bfull 是"花钱买真值"的参照）。

## 5. 训练（`e4_06_train.py`）

- LoRA：r = 16，α = 32，dropout 0.05，作用于全部线性层。
- DPO：β = 0.1，参考模型为冻结基座。Esft 的损失为回复 token 的平均 NLL。
- AdamW，10% 线性预热后恒定学习率；有效批 16；2 个 epoch；梯度裁剪 1.0；bf16 基座、fp32 LoRA 权重。
- **学习率只选一次：** 用 A′、训练种子 0，在 {5e-6, 2e-5, 5e-5} 中训练，在 tune 的 40 个游戏 × 3 次上评估，取成功率最高者（并列取较小值，`select_lr`）。结果写入 DECISIONS 后，所有臂共用。
- 每个训练臂 3 个训练种子（0、1、2）。

## 6. 评估、预测与读法

- **评估（`e4_07_eval.py`）：** 每个模型在 valid_unseen（主）与 valid_seen（复现）的每个游戏上跑 3 次。各模型在同一游戏、同一次、同一步使用相同的采样种子。
- **统计（`e4_09_analyze.py`）：** 每个游戏先对该臂全部训练种子 × 3 次取平均，臂间按游戏配对，对游戏 bootstrap 10,000 次，取百分位 95% CI，单位为百分点。
- **预测（valid_unseen）：**
  - **PL-1：** A − base 的 CI 下界 > 0。
  - **PL-2：** A − Bmatch 的 CI 下界 > −2（非劣），且 A − Cmatch 的 CI 下界 > 0。
  - **PL-3：** A − D 与 A − Rnd 的 CI 下界都 > 0。
  - **PL-4（报告项，论文重点）：** A − H 的 CI 下界 > 0。
  - **PL-5（报告项，机制）：** 在 M0 的 I 层 Fork（184 点）上，从训练后策略采 32 份草稿得到的选择收益（与 P4-X 的 X2 同法），A 三个种子的平均 − base 的轨迹 cluster bootstrap CI 下界 > 0（`e4_08_mechanism.py`）。
- **读法（按序取第一个满足者，`reading`）：**

| 读法 | 条件 | 含义 |
|---|---|---|
| **R-L-NULL** | PL-1 不成立 | 闭环不成立；论文为分析论文 |
| **R-L-HEURISTIC** | PL-3 不成立 | 收益可由"多探索"或"随便换动作"解释；如实写明 |
| **R-L-COSTLY** | PL-2 不成立 | 反馈信用有效，但不比同成本的回放更划算 |
| **R-L-WIN** | 其余 | 闭环成立 |

- 全部臂对 base 的差、A 对 Bfull / A′ / Esft 的差、valid_seen 的复现，任何读法下都报告。
