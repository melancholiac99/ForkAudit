# E5-L 设计草案（待研究者审批；不是已冻结预注册）

日期：2026-11-06。状态：**DRAFT / PRE-DATA**。**此文件不替代或修改** `exploratory_E5/PREREG_E5.md` 的原版、修订 1 或修订 2。E5-S/C/K 仍是独立的“信息 × 能力”测量实验；E5-L 是专门验证《Train on the Steps That Don’t Matter》§5.1 的另一个学习实验。

## 研究问题与可解释的估计对象

在另一个 Agent 环境——HotpotQA 多跳开放检索中，按旧策略 π₀ 的浅层执行回放筛出的 **observed-zero** 决策状态，是否仍可产生正向且不显著逊于有差距状态的离线偏好训练价值？

固定基座 Qwen2.5-7B-Instruct 与搜索环境（沿用 E5-S `search`，top-3 检索，最多 4 个动作，结果按原 E5 的检索缓存固定），使用 **HotpotQA train 仅用于训练决策点**，**HotpotQA dev 仅用于最终评估**。不以 E5-S 已预注册的 dev 测量点训练。可选排除 E5-S 使用过的 dev 题目，若 E5 的冻结任务文件在本地则自动排除。

状态定义严格复用 E4b 的浅回放协议：一个决策点事实动作加 4 个策略草稿中的合法不同替代，每臂由 π₀ 续跑 3 次：

- Z3 / zero：15 个终局奖励**全部为零**。
- V3 / gap：五臂的 3 次平均奖励**并非全部相等**。
- E3 / equal_other：五臂均值相等但不全零，计数并排除。

这里的 *zero* 不是数学上的 `Q^π(s,a)=0`，*gap* 也不等于统计显著分叉或真实正信用。分类只检验用这些观测筛数据对学习价值的影响，不检验“信用导致学习”的因果效应。

## 候选监督（同类状态固定同一规则）

每对偏好都具有相同结构：候选替代的**原始策略输出**为 `chosen`，实际事实动作的**原始策略输出**为 `rejected`，不能混用不同 token 格式，不训练时带入答案或支撑标题。两种独立标注规则形成 2×2：

- **S (support lookahead)**：对每个候选实际执行一步，从新检索结果中统计相对之前历史**新出现的 HotpotQA gold supporting article 标题**。仅当某替代比事实动作多检索到缺失的支撑文章时才输出偏好。**明确是用训练集 gold supporting_facts 的特权监督，不是无需标注的通用探索规则，也不是部署时免费的预见能力。**
- **N (novel-document lookahead)**：不看 gold，只计算候选一步结果中新出现的文档标题数。仅在事实动作与替代均为 `<search>`、替代的新标题数严格更大时输出偏好。这个规则可能学习到反重复检索，但不保证语义相关。

训练组：`Szero / Sgap / Nzero / Ngap`，以及用相同 teacher、不按信用筛选的 `Smixed / Nmixed` 作为操作性基线。全部同为 DPO，不能宣称在线 GRPO 下也成立。

## 数据预算、固定样本和可行性门

`freeze` 默认以种子 20261106 在 HotpotQA train 抽 3,000 道训练题，另 100 道**独立试点**，在 dev 抽 400 道**最终评估**题。排除 yes/no、要求两篇支撑文章标题在 wiki-18 索引中，与 E5-S 保持可比。原始任务列表、数据来源 SHA256、wiki-18 SHA256 另存，不随代码变化重抽。若试点显示样本不足，应在正式数据和任何训练结果产生前**另行审批并记录新版采样方案**；不得先读验证成绩再修改。

在正式训练池仅使用 E5 的 `rollout`、`bank --b 1`、`peek`。对每个状态检查回放重建分歧 0、实际一步观察逐字一致、4 个合法不同替代，不能自动忽略不完整的可定义状态。

各组独立无放回抽样、配对的数目相同。目标任务类型（bridge/comparison）配比按全部 V3 点的原始比例，先计算配额，再在所有 6 组取满足相同配额的最大 `16` 的倍数 `N ≤ 960`，默认至少 `N=256`；不足则**停止**，不能复制样本、放松标签、把差异写成非劣。由于零组与差距组天然访问不同状态，只配平任务类型，不能声称控制了原始回合是否成功、turn、问题难度等全部混杂。记录每组 turn/成功率/标签比例以供诊断。

样本和 SHA256 固定后做训练前 tokenizer gate：最长 `prompt + response + <|im_end|>` **≤ 6144**；长于该值立即报错，不能偷偷截断。输出完整 manifest；如原始材料不完整，停止。

## 训练、评估和预定读法

复用 E4/E4b 已验证的同一 `e4_06_train.py`：LoRA `r=16, α=32, dropout=0.05`，DPO `β=0.1`，学习率 **5e-6**，2 epochs，有效 batch 16，训练种子 0/1/2。`e5l.py train` 在明确传入 `--approved` 后才运行，正式训练前先做 `preflight`。这是故意设置的人工研究审批门，不代表已经完成冻结。

评估在 **HotpotQA dev 未见问题**上，每模型每题 3 次 rollout，共用模型间相同随机种子。指标为完整任务二元 Exact Match，任务级配对 bootstrap 10,000 次 95% CI。

主对比（百分点）：`Z = (Szero + Nzero)/2`、`G = (Sgap + Ngap)/2`、`D = Z-G`。沿用 ALFWorld 的 **4 pp 非劣界**，主结论要求：(1) Szero 与 Nzero 相对独立 base 的提升各自 CI 下界严格 > 0；(2) `D` 的 CI 下界严格 > -4 pp。报告每个 teacher 的独立 zero-gap 差、混合不筛选组与 base 的比较。无显著差异不等于统计上的非劣。

按顺序取首个读法：`E5L-NULL`（两个零组未同时证明显著收益）、`E5L-SUPPORT`（两个零组有效且合并非劣）、`E5L-COUNTER`（有差距组更好且 CI 上界 < 0）、`E5L-PARTIAL`（其他）。按当前 ALFWorld 结果设定的阈值在新环境可能功效不足，应如实报告，不允许改界限追结果。

**不能宣称**：`N` 规则保证是好查询；gold-title teacher 在部署时可用；只要 15/15 全零就是真实信用为零；DPO 等于在线 RL；静态状态选择差异是可辨认的“信用的因果效应”。
