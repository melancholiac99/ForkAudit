# E4c 预注册：不训练能否得到同样的收益（提示词与解码约束对照）

- **日期：** 2026-11-02。**状态：FROZEN / PRE-EVALUATION。** 本文件单独提交；提交时没有任何 E4c 评估结果。
- **代码：** `exploratory_E4c/`（`e4c_common.py` 规则，`e4c_eval.py` 评估，`e4c_analyze.py` 分析，`test_e4c.py` CPU 测试，`run_e4c.sh` 队列）。评估复用 E4 的游戏、种子、引擎配置、解析器与 50 步上限；对照只改提示词或在解码时重抽。
- **已知先验：** E4（R-L-HEURISTIC）与 E4b（E4b-SUPPORT）的全部结果；研究者对 38 个训练后模型评估轨迹的事后行为分析：base 的 examine / look / inventory 占步数 47%，训练后 8–25%；goto 38% → 58–78%；紧邻重复 9% → 1–4%；一局内看到目标 64% → 72–87%；看到目标后成功率基本不变；所有失败都是 50 步超时。**未见：** 任何 E4c 评估结果。
- **定位：** 事后行为分析显示，所有训练臂学到的主要是同一个搜索习惯（少看、多走）。如果一句提示词或一个解码约束就能得到同样的收益，E4 / E4b 的训练闭环就退化为"教会模型这个环境里的动作经济学"，与信用关系不大。本实验决定论文后半段按"信用"还是按"习惯"来写。

## 1. 条件

全部使用基座权重（E4 的 LoRA 引擎，不加载适配器），评估方案与 E4 完全相同：E4 `games.json` 的 valid_unseen（134 局）与 valid_seen（140 局），每局 3 次 rollout，首次抽样种子 `e4_01_rollout.seed_for`（与 E4 / E4b 全部评估共用随机数）。

| 条件 | 改动 |
|---|---|
| **base** | 无改动，在本次会话重新评估（测漂移，并作为同会话基线） |
| **P**（提示词） | 在 HCAPO 模板的可选动作行之后插入一行（全文固定，见下） |
| **R**（禁紧邻重复） | 若解析出的动作与上一步实际执行的动作相同，则重抽 |
| **PR** | P + R |
| **X**（强动作经济学约束） | 若解析出的动作是 examine / look / inventory，或与上一步相同，则重抽 |

**提示词全文（P、PR）：**
> Hint: avoid examine, look and inventory unless they are needed, and do not repeat your previous action; prefer going to locations and opening containers that you have not visited yet.

只登记这一种措辞，不尝试其他写法。

**重抽规则（R、PR、X）：** 被拒的抽样用种子 `seed + k·10¹³`（k = 1…8）重抽，取第一个不被拒的；9 次全被拒时保留最后一次（记 `kept_blocked`）。每步记录所用抽样序号、被拒动作和抽样次数。重抽改变的只是动作选择，思考文本随所选抽样一起替换，Agent 的历史只含动作与观察，与 E4 相同。

**加入 X 的理由：** 研究者提出的 (a)–(c) 中，P 可能改变不了行为，R 只针对 9% 的步。X 直接施加训练后模型表现出的那种动作分布，是"动作经济学"能做到的最强对照。若连 X 都达不到训练收益，结论才有说服力；若较弱的对照就能达到，结论同样清楚。

## 2. 终点与比较

- **主终点：** valid_unseen 的任务完成率（%）。
- **比较**（逐局配对，局内对所有 rollout 取平均，10,000 次按局 bootstrap，95% 百分位 CI，沿用 E4 的 `game_bootstrap_diff`）：
  - 各对照 − 本次 base；
  - 各对照 − **A**、− **D**：A、D 取 E4 已存的评估结果（3 个训练种子 × 3 次 rollout），这是两个参照训练臂（反馈评判者标签、探索启发式标签）；
  - A − base、D − base、A − D（用本次 base）；
  - 本次 base − E4 base（漂移）。
- **行为（操纵检查与机制，按步与按局统计）：** examine / look / inventory 占步数、goto 占步数、紧邻重复占步数、看到目标的局比例（目标词实例出现在初始观察或任一步观察中，正则代理）、看到目标后的成功率、失败中超时的比例；对照的重抽比例与保留被拒抽样的比例。E4 的 base、A、D 的同一组统计取自其存档轨迹。
- **训练后行为范围（操纵检查阈值）：** examine / look / inventory ≤ 25%，紧邻重复 ≤ 4%（E4 / E4b 训练臂在 valid_unseen 上的范围上沿）。

## 3. 读法（valid_unseen，按序取第一个满足者；δ = 4 pp，与 E4b 相同）

| 读法 | 条件 | 对论文的含义 |
|---|---|---|
| **E4c-SUBSTITUTE** | 至少一个对照的（对照 − A）CI 下界 > −4 pp | 不训练就能拿到与最好训练臂相当的收益：后半段写成"习惯"论文，训练闭环作为习惯的一种施加方式；"信用"部分只保留测量与解离 |
| **E4c-HEURISTIC-ONLY** | 否则，至少一个对照的（对照 − D）CI 下界 > −4 pp | 廉价约束能复制探索启发式臂的收益，但复制不了反馈评判者臂：A 多出的部分（操作阶段的上下文判断）是学来的 |
| **E4c-NOMANIP** | 否则，没有任何对照进入训练后行为范围 | 对照没能施加这个习惯，不能判断可替代性 |
| **E4c-LEARNED** | 否则，每个对照的（对照 − D）CI 上界都 < 0 | 训练教会的不只是表面的动作经济学；"学习 / 信用"的写法保留，习惯分析作为机制 |
| **E4c-MIXED** | 其余 | 逐个对照报告 |

"至少一个对照"含多重比较：它使 SUBSTITUTE 更容易成立，因此对"训练有额外价值"这一主张是保守的；不做校正，原样报告每个对照的区间。

**任何读法下都报告：** 全部对比、全部行为统计、重抽比例、valid_seen 上的同一组结果（只作复现，不参与读法）、base 漂移。

## 4. 解释边界

- 对照在本次会话评估，A、D 是 E4 已存结果，二者跨会话；本次 base 与 E4 base 的差异用来度量漂移。E4b 在同一服务器重评 base：valid_unseen 成功率完全相同、逐局一致率 0.851；valid_seen 低 2.4 pp。valid_seen 上的跨会话比较需按漂移解读。
- 提示词只有一种措辞；它的失败不能推广到"任何提示词都不行"。
- X 禁止 examine / look / inventory。我们认为 ALFWorld 六类任务的完成条件都不需要这三种动作；如果服务器门 S0 核对发现某类任务需要它们，则该类任务的 X 结果单独报告，读法照旧按全体计算。
- 已知限制（研究者列出）：
  - E4 的训练点只取搜索阶段（决策时 prompt 中没有目标实例，`e4_common.search_phase`），所以"只改善了搜索"部分是设计使然；看到目标后仍有约 43% 的失败，没有任何训练臂改善这部分；
  - "看到目标"是正则代理；
  - 按局相关时两边减的是同一个 base，共享它的噪声；
  - 一个模型、一个环境，examine / look 低价值是 ALFWorld 的特性。
- 操作阶段的 E4b 式 2×2 不在本实验内：E4 的点、草稿、一步返回、F 评判与回放都只覆盖搜索阶段，在操作阶段重做需要重新采点、32B 评判与回放（E4 的回放约 41,700 GPU 秒），须另行预注册。

## 5. 执行与预算

`bash run_e4c.sh`：
1. CPU 测试；
2. 门 S0：用随机策略在 2 局上跑 R、X 的管线（只验证运行，不看成功率），并核对 ALFWorld 六类任务的完成条件不含 examine / look / inventory；
3. valid_unseen 的 base、P、R、PR、X；
4. 主读法（只用 valid_unseen）；
5. valid_seen 的同五个条件；
6. 最终报告。

按 E4 经验每模型每验证集约 10 分钟；R、X 有重抽开销（base 约 9% 的步为紧邻重复、约 47% 为 examine / look / inventory，X 下这些步需要重抽）。预计共 2–2.5 GPU 小时。
