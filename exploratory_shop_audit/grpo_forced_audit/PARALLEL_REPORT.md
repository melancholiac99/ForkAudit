# 四卡执行选择（2026-11-17）

实测硬件为4×A100-SXM4-80GB、188 GiB RAM。GPU间拓扑全部PHB，P2P读可用。
研究者明确取消GPU小时上限，优化目标为墙钟时间；仍保留实际GPU成本账本。

来自同一checkpoint1、同一64条保存的真实响应。按长度稳定抽样而非奖励挑选，原生GRPO全批优势、全局mini64/micro4，optimizer.step禁用，测速不更新权重。三个配置均通过恢复模型/优化器/scheduler指纹检查；同一配置各rank梯度完全一致。跨配置有浮点归约差异，梯度范数分别1.81647、1.82038、1.81675。

这是各一次训练计算测量，包含策略/参考前向和反传，不包括模型初始化、环境采样、验证、checkpoint。不能据此断言完整实验加速2.5倍或已经穷尽所有配置。

选择四卡复制式数据并行（固定版本FSDP NO_SHARD），每卡完整7B+LoRA，只同步训练梯度。采样用4个独立TP1实例，避免7B可单卡容纳时仍跨PCIe做每层张量并行通信。阶段间独占四卡，环境与日志由一个控制器管理，独立请求seed随记录分片。保留训练组16×8、global mini64、micro4；完整micro4组在每个原mini内按token数平衡。沿用原生DP padding，divisor由4变16，明确不是跨world逐位复现。

完整已保存128条update2轨迹从checkpoint1继续训练；不重采。模型/AdamW/scheduler逐rank核验。复制checkpoint仅在全rank指纹一致后去重模型和优化器文件，分别保留各rank原生RNG。

附带训推诊断：单卡同一64条真实响应（1039 token）中，HF重算与保存vLLM概率有数值差异：sampled k3=0.01162，token ESS比例0.9942、response ESS比例0.9245，token比率超[0.8,1.2]比例2.69%。这不是“完全一致”的证明，也未据此改变普通GRPO目标或启用重要性修正。完整原始读数见evidence/parallel_20261117，后续多卡采样仍需监控。
