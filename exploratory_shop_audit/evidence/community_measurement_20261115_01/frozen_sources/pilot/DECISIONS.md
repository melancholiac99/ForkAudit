# 本轮实施决策（2026-11-15）

本目录仅执行研究者 2026-11-15「复核修订版」购物探索测量。原有 M0、E4、E5、CTHA 定义和结果不变。

## SHOP-001：先做无 GPU 的来源和数据前检

下载固定提交的完整源码归档和随库 gzip 数据，记录原始字节哈希。前检不加载策略、不推理、不使用 eval 任务生成轨迹。由于原生 `search_engine/`、转换程序和索引缺失，环境门保持 BLOCKED，不以替代检索器、模拟奖励或合成轨迹通过环境门。安装脚本引用缺失目录不能视为已经提供了检索实现。

## SHOP-002：数据初始化与完整环境验收分开

为核查加载后任务数及冻结随机价格，使用固定文件中 `clean_product_keys`、`generate_product_prices`、`load_products`、`get_price_range_above`、`get_existed_goals`、`get_goals` 的原始 AST 函数体。只移除模块导入带来的 Java、GPU、spaCy 初始化依赖；函数体不改。注入同一个 `random.Random(20261115)`、标准库依赖与无输出的进度显示。记录源文件及函数体哈希。这只验证数据初始化，不证明搜索、官方奖励、恢复或环境运行通过。今后引擎必须从这些表加载，不能重抽。

原始商品没有 `query`。原生加载器先设置 `p.get('query', '')`，然后规范化该空串；这不是 KeyError。保留该行为并报告全部 query 为空、官方 `query_match` 将始终为真的影响，不从 domain 字段自行补造 query。`reason_key` 原生默认 None。最终环境接入须检查数据路径初始化结果逐项一致。

## SHOP-003：前检阶段不提前冻结采集规模

协议数值和主种子现在登记；模型实际哈希、任务、价格、目标单独存证。采集档位必须在 20×2 试运行及 3 点吞吐测量之后冻结，当前 `selected_tier=null`。没有吞吐数据时不估填成本。前检没有分配 GPU，累计本轮 GPU 小时为 0。

## SHOP-004：抽样实现

商品大类固定为 category 按 `›` 分割后的第一级；空类为 unknown。少于 20 个独立 train 商品的小类预先合并为 other_small（unknown 保持独立）；类别合并只看数据，不看模型。每个商品组先按 SHA256(主种子、组 ID) 排序，选出一个任务代表，再按最大余数法按商品组比例分配 20 个试运行和 200 个正式任务，组间互斥。正式集 100 档使用正式任务稳定顺序的前 100 个。保留所有剩余 train 商品代表的后备顺序；不自动采集后备任务、不超出最终冻结预算。正式点位清单仍须从第 1 条真实轨迹按方案构造，不能由本清单虚构状态。

## SHOP-005：产物状态必须准确

未运行的阶段记 NOT_RUN。前检报告不叫测量结果；不创建伪造的 episodes、steps、回放库或 S/F 请求。现阶段的 CPU 测试只验证数据、抽样和记录保护；20 状态真实购买、20 前缀双进程恢复、评分隔离、可见性、A/B 续跑、规格精确最优和合成信度验收仍需后续实现与执行。未通过的环境门禁止正式采集。

## SHOP-006：环境复核优先，正式采集暂停

研究者要求先查官方补充和社区版本、运行几个完整回合，再选环境及冻结版本。该指令覆盖 SHOP-002 中可能被理解为允许正式使用空 query 快照的部分：旧快照只作失败来源证据，禁止正式采集使用，不补造 query、不删除原生评分分支。已有代码和前检目录保留。

社区候选固定到 YYHDBL/shopping-grpo-longhorizon 提交 13d2b636c0725d4e0c738b8c2eb1eb3b7592bae5。先按其完整 Environment v2.1 / Reward v3 合同进行 CPU 冒烟，不拼接为原生奖励；保留其 35 步、循环终止、规格计价、显式预算和 finish 动作。此版本商品仍缺 query，但实际 done 路径调用 evaluate_purchase，不调用历史 get_reward/query_match；这是社区已有奖励体系，不是本轮删分支绕过问题。版本比较必须写明此实质变化。

采用独立 Python 3.11 环境和社区固定依赖（其安装脚本默认 Python 3.10，此差异记录）；仅构建商品索引，不运行该仓库全套 setup.sh，以免安装／启动训练设施。冒烟使用原试点稳定顺序前 3 个 train 任务（商品和任务顺序核对后使用），基于任务文本搜索、打开实际返回的第一个商品、按可点击规格选择后购买。动作脚本仅验证真实环境调用链，不报告为模型成功率。独立进程重放同前缀，比对每步观察／合法列表／商品／规格／目标／完整会话状态及实际购买奖励；保存所有失败，不选择高奖励重跑。未完成这些核查前不冻结正式环境，也不恢复采集。

## SHOP-007：研究者选择社区环境并授权实施测量

研究者查看GitHub复核后明确选择社区环境。执行 COMMUNITY_AMENDMENT.md，原生Reward v3不改、解析缺陷显式修复、35步和循环终止保留，旧去价格公式替换为明确标注的同购买预算门消融。原投入阈值事前保留，但只解释为本轮新环境探索性规则。正常阶段无需再次确认；所有真实试点门仍必须通过，正式档位由吞吐冻结，失败留证停止。无训练、32B或main合并。
