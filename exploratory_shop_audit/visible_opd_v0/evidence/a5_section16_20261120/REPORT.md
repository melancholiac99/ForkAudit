完整包相对同格式占位文本的采样购买率差为 +22.0 个百分点（95% CI +13.5 至 +30.5）。商品包与当页证据包的同格式占位对照只用于 token 评分，行为层面的差值仍包含模板效应。

行动内容判定使用学生 top-8 加实际采样 token 的条件分布，并比较同一输出前缀上的真实包与对应占位包。至少 10% 合格位置须同时达到采样 token 中心化差绝对值 >0.02 和内容 KL >1e-5，还须覆盖至少 10 题。§16 行为门要求采样全要求购买率提升至少 10 个百分点且配对区间下界 >0。

无包学生的 1,290 个决策和 20,194 个响应 token 全部对齐。重复空包评分的最大误差为 0。本次按 §16 模板重跑全部 100 题。CPU 独立回放复核了全部 1,500 条轨迹的终止原因、终局奖励与逐步合法性。

本次追加使用 1.804 / 2.500 GPU 小时。其中新 §16 运行（全部 100 题）用量为 1.403 GPU 小时，旧版首次预检 0.190 GPU 小时在追加额度之外。实验停在 A.5；本报告未评估投影器效果或蒸馏后策略泛化。
