# T_cal 候选分布的熵和最高概率

bracket 和 following 分别是第一条命令右括号所在 token 和紧接着的下一 token。两行使用全部可定位位置，包括候选集没有 EOS 的行，且与冻结的词法类别重叠。各位置等权。

主表沿用阶段 B 原 C 和最后一层无包学生表示。完整包老师由存档 s 加居中的 full−none 还原；Huber 使用原折外输出；首块 KL 在同一 C 上用该商品对应的留出折冻结权重计算。两种投影均使用各自固定的类别收缩。另在首块原 C 上对称重算四个分布，两个存档有 28,473 个位置的完整候选集相同。每类的成对熵差、原始 top-1 和第二套支持集的结果见[完整数据](tcal_entropy.json)。
