本目录公开每个已完成更新的权重与 AdamW 状态摘要、训练合法率和两种精度的固定目标指标。每十步的正式行为评测单独保存在 [behavior](../behavior) 中。核验过的 LoRA 和 AdamW 文件保存在原实验数据卷。
