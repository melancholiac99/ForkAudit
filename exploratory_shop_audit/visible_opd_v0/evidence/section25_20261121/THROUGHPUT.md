# 四卡加速实测

同一初始 R 快照、32 个训练任务、64 条轨迹、282 条动作记录，共 4,448 个结构性有效位置。单组目标评分耗时从 309.84 秒降至 105.37 秒（含分片合并和校验），提速 2.94 倍。四张 A100 80 GiB 分别处理 76、77、59、70 条记录。学生输入与候选、候选 logits、目标和候选概率质量逐条一致。

四卡从进程启动到合并校验的平均 GPU 利用率分别为 66%、70%、82%、59%，显存峰值为 21.1、20.7、27.6、26.9 GiB。此计时覆盖单组的目标评分。三组训练及完整行为评测另行计时。

[四卡评分逐项核验](target_sharding_benchmark.json)

另在空闲卡上做了两项只读测试。把长度接近的学生前缀两条合批后，BF16 前向吞吐为原来的 1.07 倍，PyTorch 单卡峰值从 17.0 增至 19.1 GiB。397 个动作 token 位置中，36 个位置的 top-8 候选集合改变；3,176 个原候选 logits 中，1,263 个数值改变。正式评分继续使用原单条前向形状。

原生 vLLM 生成和行为评测跨卡重放的两个冷启动测试均出现部分动作差异。保留原生批次和每组固定的 GPU 位置。跨卡、引擎暖态与原生重放波动的影响未分别识别。
