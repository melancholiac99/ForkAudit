## 1. 一句话

**LLM Agent 的步级信用，在真正决定成败的分叉上，首先是一个信息问题：Agent 自身的信号、更大的评判者、完整的事后轨迹都拿不到它；只有执行候选动作一步、并按动作记录世界的回应，才拿得到。**

## 2. 标题候选

1. *Step-Level Credit Needs Counterfactual Observation, Not Bigger Judges*
2. *Hindsight Cannot See the Fork: Information, Not Capability, Limits Step-Level Credit in LLM Agents*
3. *Where Step-Level Credit Lives in LLM Agents*

## 3. 摘要草稿

> 长程 LLM Agent 的步级信用越来越多地从 Agent 自身的信号（置信度、熵、隐状态）或从评判者阅读的事后轨迹中提取。这些来源是否包含信用所需的信息？我们在 ALFWorld 上以执行回放为真值，对 3,038 个决策点、二十余万次续跑做了预注册审计。
>
> 结果：真正存在动作分叉的步很少（15.6%，零假设 3.4%），其中 64% 对"所选动作对平均"的标量信用不可见；内省信号能区分死局与活局，却定位不了分叉，熵甚至方向相反。
>
> 进一步按"决定好坏的事实是否在上下文中"把分叉分层后，出现了一个预注册的双重分离：
> - 事实在场时，更大的评判者（32B 对 7B）能选出更好的动作；
> - 事实缺失时，无论评判者规模、Agent 的完整自身历史，还是含结局的完整事后轨迹，都不优于候选集基线；
> - 而执行每个候选一步、按动作记录环境回应，能恢复 +43 个百分点，与直接读取规则（+47）相当。能力放大这份信息的价值，但不能替代它。
>
> 用这种反馈锚定的步级偏好训练策略【E4 待填】。我们在多跳检索 Agent 上预注册检验同样的分离，并在上下文给全的同题版本与完全可观察的 Sokoban 上检验一步反馈的价值是否按预测消失【E5 待填】。
>
> 这些结果表明：步级信用的瓶颈在于获取反事实观察，而不在于更强的估计器或更多的事后信息。

## 4. 故事线（引言的逻辑）

1. **问题。** 步级信用被当作估计问题：给定一条轨迹和一个终局奖励，估计每步的贡献。流行做法从两处取信号：Agent 自己（置信度加权、按熵选关键步、隐状态价值），或事后阅读轨迹的评判者（LLM 评判过程奖励、事后自蒸馏）。
2. **我们问的不同问题。** 这些来源里**有没有**信用需要的信息？要回答，需要一个有真值的参照：执行回放。
3. **先看信用本身（§3）。** 分叉稀少；标量信用看不见大部分分叉，但被掩盖的分叉里确实有可兑现的更好动作。所以重要的是"哪个动作更好"，而不只是"这一步重不重要"。
4. **内省信号能看到什么（§4）。** 结局可以，分叉不行。熵是对"已经迷路"的度量，不是对"关键性"的度量。这直接反驳按熵选关键步的做法。
5. **那信息在哪里（§5，论文核心）。** 按事实是否在上下文中分层后，做一张"评判者能看到什么"的消融表：决策上下文、自身历史、完整事后轨迹、一步反馈（打乱或不打乱对应）× 两个模型规模。只有带对应的一步反馈有用；规模只在事实在场时有用。
6. **为什么（§6，诊断）。** 没有反馈时，所有模型都把概率从"去新地方"挪开；事后轨迹让评判者锚定已执行的动作；补上缺失事实后，策略自己就消解了分叉。
7. **这有用吗（§7）。** 用一步反馈得到的步级偏好训练策略，与同等成本的回放信用、按熵选点的回放、事后评判者信用、随机换动作、"多探索"启发式比较。
8. **普遍吗，且只在该出现的地方出现吗（§8）。** 三个预注册环境：多跳检索（事实须检索，预测存在：结构读法 + 核心读法）；同一批问题但上下文给全（环境内对照，预测缺失）；Sokoban（完全可观察、难点在计算，跨环境对照，预测缺失）。关键对比是"有 − 无"的差（A-3、K-3），而不只是"又看到一次"。
9. **含义。** 预算应花在"在对的步上获取反事实观察"，而不是更大的评判者或更多的事后信息。

## 6. 贡献

1. **预注册的步级信用审计**（有执行回放真值）：内省信号定位结局、不定位分叉；熵不是关键性代理。
2. **信息 × 能力的双重分离**：在信息受限的分叉上，评判者规模、自身历史、事后轨迹都无效，只有带对应的一步反事实观察有效；在事实在场的分叉上，规模有效。
3. **诊断**：缺信息时的系统性偏移（远离新地方；事后锚定已执行动作），以及补齐信息的因果干预。
4. **闭环与泛化**：反馈锚定的步级信用的学习效果（E4）；跨环境的存在 / 缺失对照（E5：预注册预测效应在检索 Agent 上出现，在上下文给全的同题版本与 Sokoban 上消失）。

## 7. 与相关工作的定位（每篇一句，写作前逐篇核对原文）

- **CWGT：** 置信度在路由上是随机水平。我们把"无用"细化为"在哪类点上、为什么无用"，并给出有用的来源。
- **CARL、EMPG，以熵选分叉点的 ARPO / TreeRL / FR3E：** 我们在有真值、有置换对照的设置下检验熵即关键性的假设，给出反例。
- **Doomed from the Start：** 隐状态预测失败。与我们"内省信号定位结局"一致，并补上"不定位分叉"。
- **GiGPO、BiPACE：** 兄弟锚点与隐状态聚类。我们说明兄弟信号主要承载任务成功率。
- **TreeHCA、Critical-State RL、CRR：** 执行候选或分叉。我们表明一步、带对应的反馈就够；与评判者规模、事后信息做了定量对比；并给出成本匹配的学习对比。
- **LLM 评判过程奖励、事后自蒸馏、HCAPO：** 事后信息在信息受限分叉上几乎无效，并锚定已执行动作。

## 8. 必须如实写的限制与不能说的话

- P4 正式读法为 **R-MIXED**：E1 的状态级正对照选错（分层条件化掉了目标比特），所以 E1 的"内省在 I 层不过线"不作证据。§5 的结论来自 E2 / E2-M 的预注册预测，不依赖 E1。
- 分层规则以目标物体实例为唯一决定性事实，是代理。
- 7B / 32B 只是一对同家族模型，不能写成规模定律。
- 评判者打分是固定候选集上的条件概率，不是自由生成。
- "比候选集基线还差"依赖候选集构造，正文以类别分解为主。
- Fx 对强评判者不是干净对照（观察文本自带地名），F − Fx 低估对应关系的价值。
- §6 的诊断大多是事后分析；补自身历史的机制假说已被 E2-M 基本否定，要如实写。
- **不能说：** 内省信号"原则上不可能"定位分叉；新的理论贡献（信息价值、POMDP 是已有框架）；首次执行候选（TreeHCA 等已做）；"16% 的步是分叉"（必须写"检出 15.6%，零假设 3.4%"）。
